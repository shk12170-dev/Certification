# 1과목. 네트워크 일반

## 1. OSI 7계층
| 계층 | 이름 | 데이터 단위 | 핵심 기능 | 장비/프로토콜 |
|---|---|---|---|---|
| 7 | 응용 | 메시지 | 사용자 서비스 | HTTP, FTP, SMTP, DNS |
| 6 | 표현 | 메시지 | 부호화·압축·암호화 | JPEG, TLS(일부) |
| 5 | 세션 | 메시지 | 대화 제어, 동기점 | NetBIOS, RPC |
| 4 | 전송 | 세그먼트 | 종단간 신뢰성, 흐름·혼잡제어 | TCP, UDP |
| 3 | 네트워크 | 패킷 | 경로 설정, 논리주소 | IP, ICMP, **라우터** |
| 2 | 데이터링크 | 프레임 | 물리주소, 오류·흐름제어 | Ethernet, HDLC, PPP, **브리지/스위치** |
| 1 | 물리 | 비트 | 전기·기계적 전송 | **리피터/허브**, 케이블 |

- TCP/IP 4계층: 네트워크 접근(1-2) / 인터넷(3) / 전송(4) / 응용(5-7)
- 암기: "**물데네전세표응**"

## 2. 토폴로지
- 성형(Star): 중앙장치 집중, 중앙 고장 시 전체 장애, 확장 쉬움
- 버스(Bus): 한 선 공유, 충돌 발생, 종단저항(터미네이터)
- 링(Ring): 토큰 방식, 단방향, 한 노드 장애에 취약
- 트리: 계층형 / 망형(Mesh): 완전 연결 시 회선 수 = n(n−1)/2, 링크당 포트 n−1

## 3. 통신 방식
- 방향: 단방향(Simplex) / 반이중(Half) / 전이중(Full)
- 동기식(블록 단위, 클럭 동기) vs 비동기식(문자 단위, 시작/정지 비트)
- 유니캐스트 / 멀티캐스트 / 브로드캐스트 / 애니캐스트(IPv6)

## 4. 교환 방식
- **회선교환**: 전용 경로 설정, 고정 대역폭, 실시간(전화)에 적합
- **패킷교환**: 저장 후 전달, 통계적 다중화
  - 데이터그램: 패킷별 독립 경로, 순서 바뀔 수 있음
  - 가상회선: 연결 설정 후 동일 경로, 순서 보장
- 메시지교환: 메시지 전체 저장 후 전달

## 5. 다중화와 변조
- FDM(주파수), TDM(시간: 동기/통계적), WDM(파장, 광), CDM/CDMA(코드)
- 변조: ASK(진폭) · FSK(주파수) · PSK(위상) · QAM(진폭+위상)
- PCM 3단계: **표본화 → 양자화 → 부호화**
- 나이퀴스트 표본화: 최고주파수의 **2배 이상**
- 샤논 채널용량: C = B·log₂(1+S/N)
- 전송 속도: bps(bit/s), 보율(baud) — bps = baud × 비트/심볼

## 6. 오류 제어 / 흐름 제어
- 검출: 패리티, 블록합, **CRC**(다항식 나눗셈, 집중오류에 강함)
- 정정: **해밍 코드**(1비트 정정, 검출 2비트), ARQ(재전송)
- ARQ: Stop-and-Wait / **Go-Back-N**(오류 프레임부터 모두 재전송) / **Selective Repeat**(오류 프레임만)
- 흐름 제어: 정지-대기, **슬라이딩 윈도우**

## 7. 데이터링크 / MAC
- HDLC: 비트 지향, 플래그 `01111110`, 비트 스터핑(1이 5개 연속 시 0 삽입)
- PPP: 점대점, 인증 PAP/CHAP
- **CSMA/CD**: 유선 이더넷, 충돌 검출 후 백오프 (반이중)
- **CSMA/CA**: 무선 LAN, 충돌 회피 (RTS/CTS)
- 토큰 링/토큰 버스: 충돌 없음

## 8. IEEE 802 표준

|---|---|
| 802.1D | STP |
| 802.1Q | VLAN 태깅 |
| 802.1X | 포트 기반 인증 |
| 802.3 | 이더넷 (CSMA/CD) |
| 802.3ad | 링크 어그리게이션 |
| 802.11 | 무선 LAN |
| 802.15 | 블루투스/PAN |
| 802.16 | WiMAX |

### 이더넷 규격
- 10BASE-T(10M, UTP), 100BASE-TX(Fast, 100M), 1000BASE-T(Giga, UTP 4쌍), 10GBASE-T
- 광: 100BASE-FX, 1000BASE-SX(다중모드)/LX(단일모드)
- 이더넷 프레임: 최소 64B, 최대 1518B, MAC 주소 48비트(앞 24비트 OUI)
- UTP 구간 최대 **100m**

## 9. WAN
- 전용선, X.25(오류제어 강함, 저속), 프레임 릴레이(가상회선, 오류제어 생략)
- **ATM**: 고정 53바이트 셀(헤더 5 + 페이로드 48)
- MPLS(레이블 스위칭), 메트로 이더넷, xDSL(ADSL 비대칭), ISDN(2B+D)

## 10. 전송 매체
| 매체 | 특징 |
|---|---|
| UTP Cat5 | 100Mbps |
| Cat5e | 1Gbps |
| Cat6 | 1G (10G는 55m) |
| Cat6a | 10G/100m |

- UTP 배선: T568B — 주황흰/주황/녹흰/파/파흰/녹/갈흰/갈. 다이렉트(PC↔스위치), 크로스(PC↔PC, 동종 장비)

## ✍️ 연습문제
1. 6대 완전 망형 토폴로지 필요 회선 수? → **15** (6×5/2)
2. 오류 프레임부터 이후 프레임을 모두 재전송하는 ARQ? → **Go-Back-N**
3. 무선 LAN의 매체 접근 방식? → **CSMA/CA**
4. ATM 셀 크기? → **53바이트**
5. 4kHz 음성 PCM 최소 표본화 주파수? → **8kHz**
