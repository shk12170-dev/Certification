## 2. 두 자격증 한눈에 비교

| 항목 | 리눅스마스터 2급 | 네트워크관리사 2급 |
|---|---|---|
| 시행기관 | 한국정보통신진흥협회(KAIT) | 한국정보통신자격협회(ICQA) |
| 공인 여부 | 국가공인 | 국가공인 |
| 응시자격 | 제한 없음 | 제한 없음 |
| 시험 횟수 | 연 4회 | 연 4회(분기별) |
| 1차 / 필기 | 온라인 CBT, 50문항, 60분, 객관식 4지선다 | 필기, 50문항, 50분, 객관식 4지선다 |
| 2차 / 실기 | **필기(PBT) 80문항, 100분, 객관식 4지선다** | **실기(작업/서술/선택형) 1SET(1~20문항), 80분** |
| 합격 기준 | 각 차수 100점 만점 60점 이상<br>2차는 **과목당 40% 미만 과락** | 필기·실기 각 100점 만점 60점 이상 |
| 실습 필요성 | 낮음(2차도 객관식) — 단, 명령어 암기량 많음 | **높음** (랜케이블 제작 + 라우터 CLI) |
| 필기 유효기간 | 1차 합격 후 해당 회차 2차 응시 | 필기 합격일로부터 **2년 이내** 실기 응시 |
| 학점인정 | 5학점 | 있음(과정평가형 등) |

> ⚠️ 가장 많이 헷갈리는 포인트: **리눅스마스터 2급의 "2차"는 실습 시험이 아니라 객관식 필기(80문항)** 입니다. 실습 시험이 있는 건 리눅스마스터 **1급** 2차입니다.

## 5. 학습 순서 추천 (중요)

**네트워크관리사 → 리눅스마스터 순서가 정답입니다.** 이유:

1. 시험 날짜가 네트워크관리사(11/1)가 먼저입니다.
2. 네트워크관리사 NOS 과목에서 리눅스 명령어를 다루므로, **네트워크관리사 공부가 리눅스마스터의 예습**이 됩니다.
3. 리눅스마스터 "리눅스 활용" 과목의 네트워크 파트는 네트워크관리사 TCP/IP 내용과 70% 겹칩니다.

겹치는 내용은 [00_공통/중복 개념 정리.md](00_공통/중복%20개념%20정리.md)에 따로 모아두었습니다. 이 파일만 확실히 잡아도 두 시험에서 각각 10~15문항을 먹습니다.

## 6. 합격을 위한 핵심 원칙 3가지

1. **기출문제가 전부입니다.** 두 시험 모두 문제은행식 출제 비중이 매우 높습니다. 개념서 1회독 후에는 **최근 3년 기출 반복**에 시간의 70%를 쓰세요.
2. **리눅스마스터는 "명령어 옵션" 싸움입니다.** `tar`, `find`, `ps`, `chmod` 같은 명령어의 옵션 문자 하나로 정답이 갈립니다. 치트시트를 인쇄해서 들고 다니세요.
3. **네트워크관리사 실기는 손이 기억해야 합니다.** UTP 케이블 배열 순서, 라우터 CLI, 윈도우 서버 GUI 작업은 머리로 아는 것과 손으로 하는 것이 다릅니다. 케이블 도구 + Packet Tracer(바탕화면에 이미 설치되어 있음) + ICQA 실습용 에뮬레이터(자격협회 자료실)로 반복하세요.
