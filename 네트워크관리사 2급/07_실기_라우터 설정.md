# 07. 실기 — 라우터 설정 (Cisco IOS, 2급 기준)

> 2급 실기의 라우터 문제는 **ICQA 라우터 에뮬레이터**에서 CLI로 푸는 **기본 설정 작업**입니다.
> 후기 기준으로 자주 나오는 명령만 추렸습니다. OSPF·ACL·스위치 VLAN 설정 등 1급 성격의 내용은
> [12_부록_1급 수준 심화.md](12_부록_1급%20수준%20심화.md)로 분리했습니다. (이유: [00_1급-2급 범위 점검.md](00_1급-2급%20범위%20점검.md))
>
> PC에 **Cisco Packet Tracer**가 있으니 연습에 쓰되, **최종 연습은 ICQA 에뮬레이터**로 하세요(지원 명령·출력 형식이 조금 다를 수 있음).

---

## 1. 시험 푸는 요령 (후기에서 공통으로 강조하는 것)

1. **장비를 구분하세요.** 문제에 ROUTER1, ROUTER2가 있으면 지시된 장비의 콘솔에서 작업합니다. 괄호 안 값(공통 조건)은 모든 문제에서 동일합니다.
2. **지문을 글자 그대로 해석하세요.** 활성화 여부, 대소문자(패스워드 `Cisco`와 `cisco`는 다름), 로그인 여부를 놓치면 감점입니다.
3. **저장 명령을 지정하면 그 명령만** 사용합니다. 지정이 없으면 `copy running-config startup-config`.
4. 인터페이스 설정 후 **`no shutdown`**을 잊지 마세요.
5. 작업 후 `show` 명령으로 **눈으로 확인**하고 저장합니다.

---

## 2. 모드 구조

```
Router>                    사용자 모드 (User EXEC)       프롬프트 >
  │ enable (en)
Router#                    관리자 모드 (Privileged EXEC) 프롬프트 #
  │ configure terminal (conf t)
Router(config)#            전역 설정 모드
  ├ interface ...  →  Router(config-if)#      인터페이스 설정
  ├ line ...       →  Router(config-line)#    라인(콘솔/VTY) 설정
  └ router rip ... →  Router(config-router)#  라우팅 프로토콜 설정
```

| 명령 | 동작 |
|---|---|
| `enable` (`en`) | 사용자 → 관리자 모드 |
| `configure terminal` (`conf t`) | 관리자 → 전역 설정 모드 |
| `exit` | 한 단계 위로 |
| `end` / `Ctrl+Z` | 바로 관리자 모드(#)로 |
| `disable` | 관리자 → 사용자 모드 |
| `?` / `Tab` | 도움말 / 자동 완성 |
| `no 명령` | 설정 삭제 |

> Cisco IOS는 모호하지 않으면 **축약**이 됩니다: `int fa0/0`, `conf t`, `sh run`, `copy r s`.

## 3. 기본 설정 (호스트명 · 패스워드)

```cisco
Router> en
Router# conf t

Router(config)# hostname R1                      ! 호스트명 변경
R1(config)# enable password cisco                ! 관리자 모드 패스워드(평문)
R1(config)# enable secret cisco123               ! 관리자 모드 패스워드(MD5 암호화) ★
R1(config)# service password-encryption          ! 평문 패스워드 암호화 표시

! 콘솔 접속
R1(config)# line console 0
R1(config-line)# password consolepw
R1(config-line)# login                           ! 로그인 시 패스워드 요구 (없으면 설정 무의미)
R1(config-line)# exec-timeout 10 0               ! 10분 0초 무입력 시 자동 로그아웃
R1(config-line)# exit

! 텔넷 접속 (VTY 0~4 = 5개 동시 접속)
R1(config)# line vty 0 4
R1(config-line)# password telnetpw
R1(config-line)# login
R1(config-line)# exec-timeout 5 0
R1(config-line)# exit
```

| 구분 | `enable password` | `enable secret` |
|---|---|---|
| 저장 | 평문 | **MD5 해시** |
| 우선순위 | 낮음 | **높음** (둘 다 있으면 secret 적용) |

> `login`을 빠뜨리면 패스워드를 물어보지 않습니다. `exec-timeout 분 초`에서 **분이 먼저**입니다.

## 4. 인터페이스 설정 (가장 자주 나옴) ★★★

```cisco
R1(config)# interface fastethernet 0/0           ! int fa0/0
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# description To_LAN_Segment        ! 설명(대소문자·언더바 그대로)
R1(config-if)# no shutdown                       ! ★ 활성화
R1(config-if)# exit
```

### 보조 IP (secondary)
```cisco
R1(config-if)# ip address 192.168.2.1 255.255.255.0 secondary
```
> 주 IP를 **먼저** 설정한 뒤 secondary를 추가합니다. 기존 주 IP를 지우지 않습니다.

### 시리얼 인터페이스 (WAN)
```cisco
R1(config)# interface serial 2/0                 ! int s2/0
R1(config-if)# ip address 10.1.1.1 255.255.255.252
R1(config-if)# bandwidth 128                     ! 단위 kbps (라우팅 메트릭 계산용, 실제 속도 아님)
R1(config-if)# clock rate 64000                  ! ★ DCE 쪽에만 설정
R1(config-if)# encapsulation frame-relay         ! 또는 ppp / hdlc(기본값)
R1(config-if)# no shutdown
R1(config-if)# exit
```

| 항목 | 설명 |
|---|---|
| `bandwidth` | 단위 **kbps**. 실제 전송 속도를 바꾸지 않고 라우팅 프로토콜 계산에 사용 |
| `clock rate` | **DCE 쪽에만**. 단위 bps (예: 64000). DTE에는 설정 불가 |
| `encapsulation` | `hdlc`(Cisco 기본) · `ppp`(표준, 인증 지원) · `frame-relay` |
| `description` | 인터페이스 설명 |
| `no shutdown` | 인터페이스 활성화. **빠뜨리면 administratively down** |

> **양쪽 라우터의 encapsulation이 다르면** 인터페이스가 `up/down`이 됩니다.

## 5. 기본 게이트웨이 · 라우팅

```cisco
! (A) 정적 경로: ip route [목적지망] [마스크] [넥스트홉 또는 출력 인터페이스]
R1(config)# ip route 192.168.2.0 255.255.255.0 10.1.1.2
R1(config)# ip route 192.168.3.0 255.255.255.0 serial 2/0

! (B) 기본 경로(Default Route): 모르는 모든 목적지
R1(config)# ip route 0.0.0.0 0.0.0.0 10.1.1.2

! (C) 기본 게이트웨이: IP 라우팅이 꺼진 장비(스위치 등)에서 사용
R1(config)# ip default-gateway 192.168.1.254

! (D) 기본 네트워크: 클래스풀 기본 경로 후보 지정
R1(config)# ip default-network 10.0.0.0
```

| 명령 | 용도 |
|---|---|
| `ip route` | 정적 경로 (AD = 1) |
| `ip route 0.0.0.0 0.0.0.0 ...` | 기본 경로 |
| `ip default-gateway` | **라우팅 기능이 없을 때** 외부로 나가는 출구 지정 |
| `ip default-network` | 클래스풀 네트워크를 기본 경로로 지정 (RIP 등과 함께) |

> 문제에서 "**기본 게이트웨이**를 192.168.1.254로 설정"이라고 하면 `ip default-gateway`를 씁니다.

### RIP (개념과 기본 설정만)
```cisco
R1(config)# router rip
R1(config-router)# version 2
R1(config-router)# network 192.168.1.0           ! 직접 연결된 네트워크만
R1(config-router)# network 10.0.0.0
R1(config-router)# no auto-summary
```
> OSPF·EIGRP 설정은 부록(12)에 있습니다. 2급에서는 **개념**(링크 상태 vs 거리 벡터)이 단답형으로 나옵니다 → [02_TCP-IP.md](02_TCP-IP.md) §10.

## 6. DHCP 서버 설정 (후기에 등장)

```cisco
R1(config)# ip dhcp excluded-address 192.168.1.1 192.168.1.10    ! 제외 주소 (풀 만들기 전에)
R1(config)# ip dhcp pool LAN1                                    ! 풀 이름 (대소문자 주의)
R1(dhcp-config)# network 192.168.1.0 255.255.255.0
R1(dhcp-config)# default-router 192.168.1.1
R1(dhcp-config)# dns-server 8.8.8.8
R1(dhcp-config)# lease 7                                         ! 임대 7일
R1(dhcp-config)# exit
```

```cisco
R1# show ip dhcp binding             ! 할당된 주소 목록
R1# show ip dhcp pool
```

## 7. SNMP · SSH (후기 기출 흐름)

### SNMP (읽기 전용 커뮤니티)
```cisco
R1(config)# snmp-server community public ro        ! ro = 읽기 전용, rw = 읽기/쓰기
```

### SSH 전환 (Telnet → SSH)
```cisco
R1(config)# hostname R1                            ! 호스트명이 기본(Router)이 아니어야 함
R1(config)# ip domain-name example.com             ! 도메인 이름 필요
R1(config)# crypto key generate rsa                ! 키 길이 입력(예: 1024) ★
R1(config)# username admin password adminpw        ! 로컬 계정
R1(config)# line vty 0 4
R1(config-line)# login local                       ! 로컬 계정으로 로그인
R1(config-line)# transport input ssh               ! SSH만 허용 (Telnet 차단)
R1(config-line)# exit
```
> SSH는 **호스트명 + 도메인 이름 + RSA 키** 3가지가 필요합니다. 순서를 지키세요.

## 8. 설정 저장 (매우 중요) ★★★

```cisco
R1# copy running-config startup-config      ! 정식
R1# copy r s                                ! 축약
R1# write memory                            ! 구 명령 (= wr)
```
> 저장 후 `Destination filename [startup-config]?`가 나오면 **Enter**.

| 저장소 | 내용 | 휘발성 |
|---|---|---|
| **RAM** | **running-config** (현재 설정) | 휘발성 |
| **NVRAM** | **startup-config** (부팅 시 적용) | 비휘발성 |
| **Flash** | **IOS 이미지** | 비휘발성 |
| **ROM** | POST, 부트스트랩, 최소 IOS | 비휘발성 |

> `copy run start`를 하지 않으면 **재부팅 시 설정이 사라집니다.**

## 9. 확인 명령 (show) ★★★

`show`는 **관리자 모드(#)** 에서 실행합니다. 전역 설정 모드에서는 `do show ...`.

```cisco
R1# show running-config              ! 현재 설정 (sh run)
R1# show startup-config              ! 저장된 설정
R1# show ip interface brief          ! 인터페이스 IP·상태 요약 (sh ip int br)
R1# show interface                   ! 전체 인터페이스 상세
R1# show interface serial 2/0        ! 특정 인터페이스 (encapsulation, 대역폭 확인)
R1# show ip route                    ! 라우팅 테이블
R1# show version                     ! IOS 버전, 가동 시간, 메모리, 레지스터
R1# show flash                       ! Flash 내용
R1# show cdp neighbors               ! 인접 Cisco 장비
R1# show controllers serial 2/0      ! DCE/DTE 확인
R1# show clock / show users / show arp
```

### `show ip interface brief` 상태 읽기
| Status / Protocol | 의미 | 원인·조치 |
|---|---|---|
| **up / up** | 정상 | - |
| **administratively down / down** | `shutdown` 상태 | **`no shutdown`** |
| **up / down** | 물리는 정상, 2계층 프로토콜 문제 | **encapsulation 불일치**, **clock rate 미설정**, 상대편 문제 |
| **down / down** | 물리 계층 문제 | 케이블 불량·미연결 |

### `show ip route` 코드
| 코드 | 의미 |
|---|---|
| **C** | Connected (직접 연결) |
| **L** | Local (인터페이스 자체 주소) |
| **S** / **S\*** | Static / 기본 경로 |
| **R** | RIP |
| **O** | OSPF |
| **D** | EIGRP |

## 11. 연습 과제 (손으로 직접 입력해 보세요)

각 과제는 **ROUTER1 콘솔**에서 `Router>` 상태로 시작합니다. 오른쪽 열의 핵심 명령을 가리고 먼저 직접 입력해 본 뒤 확인하세요.

| # | 과제 | 핵심 명령 |
|---|---|---|
| 1 | 호스트명 `SEOUL`, 관리자 패스워드(secret) `Net2026!` | `hostname SEOUL` / `enable secret Net2026!` |
| 2 | fa0/0에 `172.16.10.1/24`, 설명 `Office_LAN`, 활성화 | `ip address 172.16.10.1 255.255.255.0` / `description Office_LAN` / `no shutdown` |
| 3 | fa0/0에 보조 IP `172.16.20.1/24` 추가 | `ip address 172.16.20.1 255.255.255.0 secondary` |
| 4 | s2/0(DCE): `10.0.0.1/30`, 대역폭 256kbps, clock rate 128000, PPP, 활성화 | `bandwidth 256` / `clock rate 128000` / `encapsulation ppp` / `no shutdown` |
| 5 | 콘솔 패스워드 `con1`, 무입력 15분 후 로그아웃 | `line console 0` / `password con1` / `login` / `exec-timeout 15 0` |
| 6 | 목적지 `192.168.50.0/24` 정적 경로, 넥스트홉 `10.0.0.2` | `ip route 192.168.50.0 255.255.255.0 10.0.0.2` |
| 7 | DHCP 풀 `OFFICE`: 네트워크 `172.16.10.0/24`, 게이트웨이 `172.16.10.1`, DNS `8.8.8.8`, `.1~.10` 제외 | `ip dhcp excluded-address 172.16.10.1 172.16.10.10` / `ip dhcp pool OFFICE` / `network ...` / `default-router ...` / `dns-server ...` |
| 8 | SNMP 읽기 전용 커뮤니티 `public` | `snmp-server community public ro` |
| 9 | VTY를 SSH만 허용 (도메인 `a.com`, 계정 `admin`/`pw1`) | `ip domain-name a.com` / `crypto key generate rsa` / `username admin password pw1` / `line vty 0 4` / `login local` / `transport input ssh` |
| 10 | 모든 설정 저장 후 인터페이스 상태 확인 | `copy running-config startup-config` / `show ip interface brief` |

## 12. 마무리 체크 문제

1. 사용자 → 관리자 모드 명령? → **`enable`**
2. 관리자 → 전역 설정 모드? → **`configure terminal`**
3. 인터페이스 활성화? → **`no shutdown`**
4. `administratively down`의 조치? → **`no shutdown`**
5. 설정 영구 저장? → **`copy running-config startup-config`**
6. running-config / startup-config / IOS 저장 위치? → **RAM / NVRAM / Flash**
7. DCE 쪽에만 설정하는 명령? → **`clock rate`**
8. `bandwidth`의 단위와 의미? → **kbps, 라우팅 메트릭 계산용(실제 속도 불변)**
9. 주 IP를 두고 두 번째 IP를 추가? → **`ip address ... secondary`**
10. 라우팅 기능이 없는 장비의 기본 게이트웨이? → **`ip default-gateway`**
11. 기본 경로 명령? → **`ip route 0.0.0.0 0.0.0.0 넥스트홉`**
12. `enable password`와 `secret` 중 우선? → **secret**
13. `exec-timeout 10 0`의 의미? → **10분 0초**
14. 콘솔 패스워드 설정 시 반드시 필요한 명령? → **`login`**
15. SSH 사용에 필요한 3가지? → **호스트명 + 도메인 이름 + RSA 키**
16. Telnet 차단하고 SSH만 허용? → **`transport input ssh`**
17. SNMP 읽기 전용 커뮤니티? → **`snmp-server community 이름 ro`**
18. DHCP 제외 주소 명령의 위치? → **전역 설정 모드(`ip dhcp excluded-address`)**
19. `up/down`의 흔한 원인 2가지? → **encapsulation 불일치, clock rate 미설정**
20. 인터페이스 IP·상태를 요약해서 보는 명령? → **`show ip interface brief`**
21. `show ip route`의 C, S, R? → **Connected / Static / RIP**
22. DCE/DTE 확인 명령? → **`show controllers serial 번호`**
23. 인접 Cisco 장비 확인? → **`show cdp neighbors`**
24. `end`와 `exit`의 차이? → **end = 바로 관리자 모드, exit = 한 단계 위**
