# 네트워크관리사 2급 — 시험 개요 · 일정 · 합격 전략

> 📌 **2026-10-09 개정**: 1급 수준 내용은 부록으로 분리하고, 2급 실기(윈도우 서버 GUI 등)와 공식 필기 범위 누락분을 보강했습니다. 내역은 [00_1급-2급 범위 점검.md](00_1급-2급%20범위%20점검.md) 참고.

## 2. 시험 구성

| 구분 | 필기 | 실기 |
|---|---|---|
| 문항 수 | **50문항** | **1 SET (1~20문항)** |
| 문제 유형 | 객관식 4지선다 | **작업형 / 서술형 / 선택형** |
| 시험 시간 | **50분** | **80분** |
| 합격 기준 | 100점 만점 **60점 이상** | 100점 만점 **60점 이상** |
| 응시 자격 | 제한 없음 | 해당 등급 필기 합격자 (2년 이내) |

### 필기 출제 과목 (4과목)
| 과목 | 문항 수 | 주요 내용 |
|---|---|---|
| **네트워크 일반** | 과목별 5~18문항 | OSI 7계층, 토폴로지, 전송매체, 통신방식 |
| **TCP/IP** | 과목별 5~18문항 | IP 주소, 서브네팅, 프로토콜, IPv6 |
| **NOS** | 과목별 5~18문항 | 윈도우 서버, 리눅스 서버 관리 |
| **네트워크 운용기기** | 과목별 5~18문항 | 허브·스위치·라우터, VLAN, RAID, 케이블 |

> 과목별 문항 수는 회차마다 달라집니다. 공식 안내상 합격 기준은 **총점 60점 이상**이며 과목별 과락 규정은 확인되지 않았습니다(접수 안내 재확인 권장).
> 일부 교재·블로그에는 '정보보호개론'이 별도 과목으로 나오지만 공식 안내 페이지에는 없습니다. 공식 출제기준 PDF로 최종 확인하세요.

### 실기 출제 유형 (합격 후기 기준)
| 유형 | 방식 | 내용 |
|---|---|---|
| **UTP 케이블 제작** | 실물 작업, 1번 문제 약 6.5점 | 다이렉트/크로스 제작 (장비 그룹 판단 + 배열) |
| **라우터 설정 (Cisco IOS)** | 에뮬레이터 CLI | 인터페이스·secondary IP·정적 경로·패스워드·DHCP·SNMP·SSH·저장 |
| **윈도우 서버 설정** | 에뮬레이터 **GUI** | IP 설정, DNS, DHCP, FTP, IIS, 사용자/그룹, 로컬 보안 정책, 서비스 |
| **단답·선택형** | 필기식 | 프로토콜·계층, 서브넷 계산, 리눅스 명령, 보안 용어(IPSec·WAF 등) |

> 케이블 채점은 **선 배열 순서, 끝단이 커넥터 끝까지 닿았는지, 빠지지 않는지**를 봅니다. 완벽한 미관보다 **배열 정확도**가 중요합니다.

## 4. 합격 전략

### 필기 — 3단계 공략
```
1단계 (1주): OSI 7계층 + 계층별 프로토콜·장비 완전 암기
             → 이것만으로 10문항 이상 확보
2단계 (2주): TCP/IP + 서브네팅
             → 서브네팅은 반복 계산 연습이 전부. 가장 확실한 득점원
3단계 (2주): NOS + 운용기기 + 기출 10회차 폭격
             → 기출에서 본 문제가 그대로 나오는 경우가 많음
```

### 이 시험의 특징 (중요)
1. **문제은행 성향이 매우 강합니다.** ICQA가 자료실에 기출문제를 직접 공개하므로 반드시 받아서 푸세요.
2. **50문항 50분** = 문항당 1분. 서브네팅 계산 문제는 시간을 잡아먹으니 **계산법을 손에 익혀 30초 내에 풀 수 있게** 만들어야 합니다.
3. **과락 규정은 공식 안내에서 확인되지 않았습니다(총점 60점 기준).** NOS(윈도우 서버 GUI 메뉴 위치 같은 문제)가 약하면 과감히 후순위로 두고, 네트워크 일반·TCP/IP·운용기기에서 점수를 확보하세요.

### 실기 — 반드시 손으로 연습
1. **UTP 케이블**: 배열 순서를 외우는 것만으로는 부족합니다. 시험장에서 제한 시간 안에 만들어야 하므로 **실제로 5회 이상 제작**해보세요. (랜툴 + Cat5e 케이블 + RJ-45 커넥터를 문구점/인터넷에서 1만원대로 구입 가능)
2. **라우터 설정**: PC에 이미 **Cisco Packet Tracer**가 설치되어 있습니다(최종 연습은 ICQA **라우터 에뮬레이터**로). 이걸로 `enable` → `configure terminal` → 인터페이스 설정 → `copy running-config startup-config` 흐름을 손이 기억할 때까지 반복하세요.
3. **윈도우 서버 GUI**: IIS·FTP·DHCP·DNS·사용자/그룹·로컬 보안 정책·서비스·IP 계산 8개 영역을 **ICQA 실습용 에뮬레이터**로 반복하세요. 같은 주제의 1번/2번 변형이 반복 출제된다는 후기가 많습니다. (자세한 절차: [08_실기_서버 명령어.md](08_실기_서버%20명령어.md))
4. **단답형**: 계층별 프로토콜, 서브넷 계산, 리눅스 명령(traceroute·chmod·fstab 등), 보안 용어를 키워드로 정리하세요.
