# 00. 1급 vs 2급 범위 점검 및 자료 보정 내역

> 점검일: 2026-10-09 · 대상: 이 폴더의 2급 자료 전체
> **결론: 자료는 2급 용으로 작성했지만, ① 1급 수준 내용이 일부 섞여 있었고 ② 2급 실기의 핵심(윈도우 서버 GUI 작업)이 빠져 있었습니다.** 아래와 같이 보정했습니다.

---

## 1. 1급과 2급은 출제 범위가 같은가? → 같지 않습니다

| 구분 | 2급 | 1급 |
|---|---|---|
| 자격 성격 | **국가공인** (ICQA 공식 안내) | 등록(비공인) 민간자격 |
| 응시 자격 | 제한 없음 | 출처마다 다름(2급 취득자/경력자 조건 vs 제한 없음) — 접수 전 확인 필요 |
| 필기 | 50문항 · 50분 · 60점 이상 | 60문항 · 60분 (블로그 기준, 36문항 이상) |
| 필기 범위 | 네트워크 일반 · TCP/IP · NOS · 운용기기 | **2급과 약 70% 유사** + 보안 문제, RIP·OSPF 등 고급 프로토콜 추가 (블로그 추정치) |
| 실기 | **UTP 케이블 제작** + 라우터 기본 설정 + **윈도우 서버 GUI 작업** + 단답/선택형, 80분 | 케이블 제작 **없음**, RIP·OSPF 라우터 설정 + 윈도우 서버 **보안** + 리눅스 명령어 (블로그 기준) |

- 1급 수치(문항 수·실기 시간)는 출처 간에 서로 달라 **참고용**입니다. 지금은 2급만 준비하므로 2급 수치만 믿으면 됩니다.
- 근거: [ICQA 2급 안내](https://www.icqa.or.kr/cn/page/network), [1급 난이도·준비 정리(블로그)](https://www.jisicknavi.com/2025/08/network-administrator-level1.html), [1·2급 차이 정리(링커리어)](https://community.linkareer.com/employment_data/4959061)

## 3. 2급 심화 표시 (본문에 남겨두되 우선순위 낮음)

다음은 **개념은 필기·단답형에 나오지만 깊게 파고들 필요는 없는** 항목입니다. 각 파일에 `⚠️ 심화` 표시를 달았습니다.

- BGP·EIGRP 세부, STP 포트 타이머 수치·MSTP, AD(관리 거리) 표, RIP 루프 방지 기법 전체
- VLSM·경로 요약(Supernetting) — 호스트 수 → 프리픽스, 네트워크/브로드캐스트 계산이 우선

## 5. 아직 확인하지 못한 것 (솔직한 한계)

1. **ICQA 출제기준 변경 공지(2025.1.13) 첨부파일**은 열어보지 못했습니다. 공식 PDF로 한 번 대조하는 것이 가장 정확합니다.
2. 실기 내용은 **합격 후기(블로그)** 기반입니다. 배점·세부 메뉴는 회차마다 다를 수 있습니다.
3. 윈도우 서버 GUI 가이드는 일반적인 Windows Server(IIS·DNS·DHCP 관리자) 메뉴 기준입니다. **ICQA 실습용 에뮬레이터의 메뉴 이름과 약간 다를 수 있습니다.**
4. 필기 과목에 "정보보호개론"이 별도로 있는지는 자료마다 달라, 공식 PDF 확인 전까지는 **11번 파일을 단답형 대비용으로만** 쓰세요.

- ICQA 사이트 자료실에서 **「네트워크관리사 실습용 에뮬레이터」와 「모의고사 예제 프로그램」**을 내려받아 08·07번 가이드대로 직접 클릭·타이핑해 보세요. (제가 대신 내려받지는 않았습니다.)
