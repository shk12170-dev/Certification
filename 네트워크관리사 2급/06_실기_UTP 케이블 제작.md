# 06. 실기 — UTP 케이블 제작

> 실기 **1번 문제**로 출제되며 배점은 약 **6.5점**입니다.
> 배점은 크지 않지만 **가장 확실하게 먹고 들어가는 문제**이고, 못 만들면 그대로 날립니다.
> **머리로 외우는 것과 손으로 만드는 것은 완전히 다릅니다. 반드시 실물로 연습하세요.**

---

## 1. 반드시 외울 배열 (이것만은 완벽히)

### T568B (표준, 실기에서 주로 요구) ★★★
```
핀 1 ─ 흰주 (주백)
핀 2 ─ 주
핀 3 ─ 흰녹 (녹백)
핀 4 ─ 파
핀 5 ─ 흰파 (파백)
핀 6 ─ 녹
핀 7 ─ 흰갈 (갈백)
핀 8 ─ 갈
```
**암기 문장: 흰주-주-흰녹-파-흰파-녹-흰갈-갈**
줄여서: **"주주녹파파녹갈갈"** (1·3·5·7번이 흰 줄무늬)

### T568A
```
핀 1 ─ 흰녹    핀 2 ─ 녹    핀 3 ─ 흰주    핀 4 ─ 파
핀 5 ─ 흰파    핀 6 ─ 주    핀 7 ─ 흰갈    핀 8 ─ 갈
```
**A와 B의 차이 = 주황 쌍과 녹색 쌍이 서로 바뀐 것뿐입니다.** (4,5,7,8번은 동일)

## 2. 케이블 종류별 제작 방법

| 종류 | 한쪽 끝 | 반대쪽 끝 | 용도 |
|---|---|---|---|
| **다이렉트(Straight)** | **T568B** | **T568B** | PC↔허브, PC↔스위치, 스위치↔라우터 |
| **크로스(Cross-over)** | **T568B** | **T568A** | PC↔PC, 스위치↔스위치, 라우터↔라우터, **PC↔라우터** |
| 롤오버(콘솔) | T568B | 완전 역순 (8-7-6-5-4-3-2-1) | PC↔라우터 콘솔 포트 |

### 기억법
> **"다른 장비끼리 = 다이렉트, 같은 장비끼리 = 크로스"**
> 단, **PC ↔ 라우터는 크로스** (둘 다 종단 장비로 봄) — 함정 단골

### 크로스 케이블 반대쪽 배열 (A 배열)
```
흰녹 - 녹 - 흰주 - 파 - 흰파 - 주 - 흰갈 - 갈
```
> 실질적으로 **1↔3, 2↔6이 교차**합니다 (송신 1,2 ↔ 수신 3,6).

## 2-1. 장비 그룹(MDI / MDI-X) 판단법 ★★★ (실기 1번 문제의 첫 관문)

케이블 종류를 정하는 가장 빠른 방법은 **장비를 두 그룹으로 나누는 것**입니다(후기 기준).

| 그룹 | 장비 | 포트 성격 |
|---|---|---|
| **A 그룹 (MDI)** | **PC, 라우터, 서버** | 1,2번으로 송신 / 3,6번으로 수신 |
| **B 그룹 (MDI-X)** | **스위치, 허브** | 1,2번으로 수신 / 3,6번으로 송신 |

```
서로 다른 그룹을 연결  →  다이렉트
같은 그룹끼리 연결     →  크로스
```

| 연결 | 그룹 | 케이블 |
|---|---|---|
| PC ↔ 스위치 | A–B | 다이렉트 |
| PC ↔ 허브 | A–B | 다이렉트 |
| 라우터 ↔ 스위치 | A–B | 다이렉트 |
| PC ↔ PC | A–A | **크로스** |
| **PC ↔ 라우터** | A–A | **크로스** |
| 서버 ↔ 라우터 | A–A | 크로스 |
| 스위치 ↔ 스위치 | B–B | **크로스** |
| 스위치 ↔ 허브 | B–B | **크로스** |
| 허브 ↔ 허브 | B–B | 크로스 |

### 특수 규칙 (후기에서 강조)
- **허브끼리 연결하되 한쪽이 업링크(Uplink) 포트**를 쓰면, 업링크 포트가 내부적으로 교차를 해 주므로 **다른 장비 연결로 보고 다이렉트**로 만듭니다.
- 문제에 **"기존 케이블은 Cross" 같은 추가 조건**이 붙으면 지문의 조건에 따라 판단이 뒤바뀔 수 있으니 **지문을 끝까지** 읽으세요. (구체적 출제 형태는 ICQA 모의고사 예제 프로그램으로 확인)
- **케이블 길이는 감점 요인이 아닙니다.** 채점은 ① 배열 순서 ② 끝까지 닿았는지 ③ 빠지지 않는지만 봅니다.

## 3. 핀별 실제 역할 (10/100Mbps 기준)

| 핀 | 신호 | 역할 |
|---|---|---|
| **1** | TX+ | 송신 + |
| **2** | TX- | 송신 - |
| **3** | RX+ | 수신 + |
| 4 | - | 미사용 |
| 5 | - | 미사용 |
| **6** | RX- | 수신 - |
| 7 | - | 미사용 |
| 8 | - | 미사용 |

> **100Mbps까지는 1,2,3,6번 4가닥만 사용**합니다.
> **1Gbps(1000BASE-T)는 8가닥 전부** 사용합니다.
> "4가닥만 연결해도 100Mbps 통신이 되는가?" → **예** (시험 단골)

## 4. 제작 절차 (시험장 순서)

```
1. 케이블 외피 벗기기
   - 스트리퍼(랜툴의 칼날 부분)로 끝에서 약 2~3cm 지점을 돌려 자름
   - 내부 8가닥이 상하지 않게 살살 돌릴 것

2. 꼬임 풀기
   - 4쌍(8가닥)의 꼬임을 풀어 펴줌
   - 꼬임을 푼 길이가 너무 길면 성능 저하(시험에선 큰 문제 없음)

3. 배열 순서대로 정렬
   - 왼쪽부터 흰주-주-흰녹-파-흰파-녹-흰갈-갈
   - 손가락으로 꽉 눌러 평평하게 만들기 ★ 여기가 핵심

4. 끝 길이 맞춰 자르기
   - 커터로 한 번에 수평으로 자름
   - 외피 끝에서 약 1.2~1.4cm 남기기
   - 너무 길면 외피가 커넥터에 안 물리고, 너무 짧으면 핀에 안 닿음

5. RJ-45 커넥터에 삽입
   - 커넥터 **클립(걸쇠)이 아래**로 가게 잡으면 1번이 왼쪽
   - 8가닥을 동시에 끝까지 밀어 넣기
   - 투명 커넥터 앞쪽에서 8가닥이 모두 끝에 닿았는지 확인 ★
   - 외피가 커넥터 내부까지 들어가 있는지 확인

6. 압착(크림핑)
   - 랜툴 RJ-45 홈에 넣고 손잡이를 끝까지 꽉 누름
   - "딸깍" 소리가 나고 금속 핀이 눌린 것 확인

7. 반대쪽도 동일하게 제작
   - 다이렉트: 같은 배열 / 크로스: A 배열

8. 랜 테스터로 검사
   - 1~8번 LED가 순서대로 점등되면 다이렉트 정상
   - 크로스는 1-3, 2-6이 교차해서 점등
```

## 5. 채점 기준 (후기 기반)

채점자는 **완성된 케이블의 커넥터를 눈으로 확인**합니다. 주로 보는 것:

| 항목 | 확인 내용 |
|---|---|
| ✅ **배열 순서** | 투명 커넥터 너머로 8가닥 색 순서가 맞는가 (**가장 중요**) |
| ✅ **끝까지 닿았는가** | 8가닥 모두 커넥터 맨 앞까지 밀려 들어갔는가 |
| ✅ **빠지지 않는가** | 살짝 당겨도 선이 빠지지 않는가 (압착 제대로) |
| ✅ **외피 물림** | 외피가 커넥터 안쪽까지 들어가 고정되었는가 |
| △ 미관 | 꼬임 푼 길이 등은 크게 보지 않음 |

> 후기에 따르면 **배열이 정렬됐는지, 끝 부분에 잘 닿았는지, 빠지지 않는지**만 체크합니다.
> 미관보다 **정확한 색 순서**가 압도적으로 중요합니다.

## 6. 실수 TOP 5와 예방법

| 실수 | 결과 | 예방 |
|---|---|---|
| **주황과 갈색 혼동** | 배열 오답 | 밝은 곳에서 확인, 주황이 더 밝음 |
| **흰색 줄무늬 가닥의 짝 혼동** | 1,3번 순서 바뀜 | 흰주는 주황과, 흰녹은 녹색과 짝 |
| **커넥터 방향 착각** | 좌우 반전 | **클립이 아래를 향할 때 왼쪽이 1번** |
| 선이 끝까지 안 들어감 | 도통 불량 | 투명 커넥터 앞쪽에서 8개 구리선 확인 |
| 자른 길이가 제각각 | 일부 핀 미접촉 | 한 번에 수평으로 자르기 |

### 커넥터 방향 확실히 잡는 법
```
   클립(걸쇠)이 뒤/아래로 가게, 구멍이 나를 향하게 잡았을 때
   ┌─────────────┐
   │ 1 2 3 4 5 6 7 8 │   ← 왼쪽이 1번
   └───┐   ┌─────┘
       └───┘  (클립은 반대편)
```

## 7. 자가 연습 계획

### 준비물 (온라인/문구점에서 1~2만원)
- UTP Cat5e 케이블 3m 이상
- RJ-45 커넥터 20개 이상 (실패를 감안해 넉넉히)
- **랜툴(크림핑 툴)** — 압착 + 스트리퍼 + 커터 일체형
- 랜 테스터 (선택, 있으면 좋음)

### 연습 목표
| 회차 | 목표 |
|---|---|
| 1~2회 | 절차 익히기 (시간 무관) |
| 3~4회 | 배열 보지 않고 제작 |
| 5회 이상 | **5분 내 한쪽 끝 완성** |
| 최종 | 다이렉트 1개, 크로스 1개를 각각 10분 내 완성 |

> 시험장에서는 보통 재료가 제공되지만, **공지사항에서 지참물을 반드시 확인**하세요.

## 8. 필기에서도 나오는 케이블 문제

| 문제 유형 | 답 |
|---|---|
| PC ↔ 스위치 | 다이렉트 |
| PC ↔ 허브 | 다이렉트 |
| 스위치 ↔ 라우터 | 다이렉트 |
| 스위치 ↔ 허브 | **크로스** |
| 스위치 ↔ 스위치 | 크로스 |
| 허브 ↔ 허브 | 크로스 |
| PC ↔ PC | 크로스 |
| 라우터 ↔ 라우터 | 크로스 |
| **PC ↔ 라우터** | **크로스** |
| PC ↔ 라우터 콘솔 포트 | **롤오버(콘솔) 케이블** |

> **규칙**: 같은 계층(같은 종류) 장비끼리 = 크로스 / 다른 계층 = 다이렉트
> 단, PC와 라우터는 둘 다 "종단 장비"로 간주해 **크로스**.

### T568B 순서 확인 문제 (자주 나옴)
- "T568B에서 3번 핀의 색은?" → **흰녹(녹백)**
- "T568B에서 6번 핀의 색은?" → **녹**
- "T568A에서 1번 핀의 색은?" → **흰녹**
- "다이렉트 케이블에서 양쪽 3번 핀의 색은?" → 둘 다 **흰녹**
- "크로스 케이블에서 교차되는 핀 번호는?" → **1↔3, 2↔6**
- "100BASE-TX에서 실제로 사용하는 핀 번호는?" → **1, 2, 3, 6**

## 9. 시험 직전 1분 체크

```
T568B : 흰주 - 주 - 흰녹 - 파 - 흰파 - 녹 - 흰갈 - 갈
T568A : 흰녹 - 녹 - 흰주 - 파 - 흰파 - 주 - 흰갈 - 갈
        (A와 B는 주황쌍 ↔ 녹색쌍만 교환)

다이렉트 = B + B    (다른 종류 장비)
크로스   = B + A    (같은 종류 장비, PC↔라우터 포함)
롤오버   = 완전 역순 (콘솔 접속용)

사용 핀: 100Mbps = 1,2,3,6 / 1Gbps = 1~8 전부
클립 아래 → 왼쪽이 1번
```
