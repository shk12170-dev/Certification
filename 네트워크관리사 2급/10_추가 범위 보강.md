# 10. 추가 범위 보강 — 고속 LAN · WAN · 설계 · 패킷 분석 · 최신 기술 · 운용기기

> 공식 필기 범위(네트워크 일반 · TCP/IP · NOS · 운용기기) 중 기존 자료에 약했던 부분을 모았습니다.

## 1. 고속 LAN 기술

### 이더넷 진화
| 구분 | 속도 | 표준 | 매체 |
|---|---|---|---|
| Ethernet | 10Mbps | 802.3 | UTP Cat3 |
| **Fast Ethernet** | 100Mbps | 802.3u | UTP Cat5 (100BASE-TX), 광 (100BASE-FX) |
| **Gigabit Ethernet** | 1Gbps | 802.3z(광) / **802.3ab**(UTP 1000BASE-T) | UTP Cat5e, 광 |
| 10 Gigabit | 10Gbps | 802.3ae | 광 (UTP는 Cat6a) |
| 40/100 Gigabit | 40/100Gbps | 802.3ba | 광 |

### 그 밖의 LAN 방식
| 방식 | 특징 |
|---|---|
| **Token Ring (802.5)** | 토큰 패싱, 4/16Mbps, 링 구조 |
| **FDDI** | 광섬유 기반 100Mbps **이중 링(Dual Ring)** 토큰 방식. 장애 시 보조 링으로 우회 |
| **ATM** | **고정 길이 53바이트 셀(헤더 5 + 페이로드 48)**, 셀 교환, 가상 회선(VPI/VCI), 155/622Mbps |

### 이더넷 프레임 구조 (자주 출제)
```
프리앰블 7B | SFD 1B | 목적지 MAC 6B | 출발지 MAC 6B | Type/Length 2B | 데이터 46~1500B | FCS 4B
```
- 최소 프레임 **64B**, 최대 **1518B** (헤더~FCS, 프리앰블 제외). 데이터가 46B보다 작으면 **패딩**
- **FCS = CRC-32** 오류 검출
- Type 값: `0x0800` IPv4, `0x0806` ARP, `0x86DD` IPv6, `0x8100` 802.1Q VLAN 태그

### 기타 LAN 기술
| 기술 | 설명 |
|---|---|
| **Auto-Negotiation** | 속도·듀플렉스 자동 협상. **듀플렉스 불일치** 시 late collision·CRC 오류 증가 |
| **Link Aggregation (802.3ad, LACP)** | 여러 포트를 묶어 대역폭 확장 + 이중화 |
| **PoE** | 802.3af 15.4W / 802.3at 30W / 802.3bt 60·90W |
| **Jumbo Frame** | MTU를 9000바이트 안팎으로 확대 (스토리지망) |

## 2. WAN · 광대역 통신

| 방식 | 계층/종류 | 특징 |
|---|---|---|
| **PSTN** | 회선 교환 | 아날로그 전화망, 모뎀 사용 |
| **ISDN** | 회선 교환 | **BRI = 2B+D = 144kbps** (B 64k ×2 + D 16k) / **PRI = 23B+D (T1, 1.544Mbps)** 또는 30B+D (E1, 2.048Mbps) |
| **전용선 T1/E1/T3/E3** | 회선 | T1 **1.544Mbps (24채널)**, E1 **2.048Mbps (32채널)**, T3 44.736M, E3 34.368M |
| **X.25** | 패킷 교환, 3계층 | 오류·흐름 제어가 많아 느림 |
| **Frame Relay** | 패킷 교환, **2계층** | X.25의 오류 제어를 생략해 빠름. **DLCI**로 가상회선 식별, PVC/SVC, CIR(약정 속도) |
| **ATM** | 셀 교환 | 53B 셀, QoS 우수 |
| **MPLS** | 2.5계층 | **레이블** 기반 스위칭, 트래픽 엔지니어링·VPN |
| **Metro Ethernet** | 도시권 이더넷 | 이더넷 기반 WAN |

### xDSL · 접속망
| 기술 | 특징 |
|---|---|
| **ADSL** | **비대칭**(다운 > 업), 기존 전화선 사용, 전화와 동시 사용 가능 (다운 최대 약 8Mbps, ADSL2+ 약 24Mbps) |
| **VDSL** | 짧은 거리에서 고속 (수십 Mbps) |
| SDSL | 대칭형 |
| **케이블 모뎀** | CATV 동축 + 광 (**HFC**), **공유 매체**라 이용자 많으면 속도 저하 |
| **FTTH / FTTB / FTTC** | 광케이블을 집/건물/구역 단자까지 |

### 광 전송
| 기술 | 설명 |
|---|---|
| **SONET (미국) / SDH (국제)** | 광 동기 전송. OC-1 51.84Mbps, **OC-3 = STM-1 = 155.52Mbps**, OC-12 = STM-4 = 622.08Mbps |
| **WDM / DWDM** | **한 광섬유에 여러 파장** 동시 전송 |

#### WDM(파장 분할 다중화)의 특징 (2026-2회 20번)
- **광학적(파장 축)** 으로 다중화합니다 — 시간축 다중화(TDM)가 아닙니다.
- 파장(채널)마다 **서로 다른 전송 형식·속도·프로토콜**을 수용합니다(프로토콜 투명성). ‘각 채널이 같은 형식·속도’는 ✗
- **광증폭기**를 사용해 **무중계 장거리 전송**이 가능합니다.
- **기존 광섬유 선로를 증설하지 않고** 파장을 추가해 **회선(용량)을 쉽게 확장**합니다. ‘선로 증설 없이는 증설이 어렵다’는 ✗
- CWDM(저비용·적은 채널) / DWDM(고밀도·장거리)

## 3. 다중화 · 변조 · 부호화

### 다중화
| 방식 | 설명 |
|---|---|
| **FDM** | 주파수 분할 (아날로그) |
| **TDM** | 시간 분할. **동기식**(고정 슬롯) / **통계적**(필요한 만큼, 효율 높음) |
| **WDM** | 파장 분할 (광) |
| **CDM(CDMA)** | 코드 분할 (이동통신) |

### 변조
| 방식 | 변화시키는 것 |
|---|---|
| ASK | 진폭 |
| FSK | 주파수 |
| PSK | 위상 |
| **QAM** | 진폭 + 위상 (고속 모뎀·Wi-Fi) |

### PCM (아날로그 → 디지털)
```
표본화(Sampling) → 양자화(Quantization) → 부호화(Encoding)
```
- **나이퀴스트 표본화 정리**: 표본화 주파수 ≥ 신호 최고 주파수의 **2배**
- 음성 4kHz → 8,000샘플/초 × 8비트 = **64kbps** (G.711)

### 용량·속도 공식
- **bps = baud × 심볼당 비트 수**
- 샤논 용량: C = B · log₂(1 + S/N) (잡음 있는 채널)
- 나이퀴스트 용량: C = 2B · log₂M (잡음 없는 채널)

### 선로 부호화
| 방식 | 사용처 |
|---|---|
| NRZ / RZ | 기본 방식 |
| **Manchester** | **10Mbps 이더넷** (비트 중앙에서 전이, 클럭 포함) |
| Differential Manchester | Token Ring |
| **4B/5B** | 100BASE-TX, FDDI |
| **8B/10B** | 기가비트 광 이더넷, Fibre Channel |

## 4. 네트워크 설계 · 구축

### 설계 절차
```
요구사항 분석 → 논리 설계 → 물리 설계 → 구축(시공) → 시험·검증 → 운영·문서화
```

### 3계층 계층적 설계
| 계층 | 역할 |
|---|---|
| **Core** | 고속 백본, 이중화, 단순 전달에 집중 |
| **Distribution** | 정책 적용, VLAN 간 라우팅, 집선 |
| **Access** | 단말(PC) 연결, 포트 보안, VLAN 할당 |

### 구내 배선
| 구분 | 설명 |
|---|---|
| **수평 배선** | 층 배선반(IDF) ↔ 작업 영역. **영구 링크 90m + 패치 코드 10m = 최대 100m** |
| **수직(백본) 배선** | 층간·건물 내 간선, 광케이블 사용 |
| **캠퍼스 배선** | 건물 간 연결 |
| **MDF / IDF** | 주 배선반 / 층 배선반 |
| **패치 패널** | 케이블 정리·변경 용이 |
| 표준 | **TIA/EIA-568**(T568A/B), ISO/IEC 11801 |

> 전력선과 이격해 배선(전자기 간섭 방지), 케이블에 라벨링, 여유 길이 확보.

### 가용성 · 품질
| 항목 | 내용 |
|---|---|
| 이중화 | 링크·장비·전원. STP/RSTP, LACP |
| 게이트웨이 이중화 | **HSRP(Cisco) / VRRP(표준)** — 가상 IP를 공유 |
| **QoS** | 대역폭 보장·우선순위. 802.1p(CoS), DSCP(DiffServ), 큐잉(FIFO·PQ·WFQ) |
| 주소 설계 | 사설 IP + 서브넷, 확장성 고려 |

## 5. 패킷 분석

### 도구
| 도구 | 특징 |
|---|---|
| **Wireshark** | GUI 패킷 캡처·분석 |
| **tcpdump** | CLI 패킷 캡처 |
| **NMS / 프로토콜 분석기** | 트래픽 모니터링 |

### 캡처 원리
- **프로미스큐어스(Promiscuous) 모드**: 자기 앞이 아닌 프레임도 수신
- **허브** 환경: 모든 트래픽이 보이므로 바로 캡처 가능
- **스위치** 환경: **포트 미러링(SPAN)** 또는 TAP 장비 필요

### Wireshark 필터 (캡처 필터와 디스플레이 필터 구분)
```
# 디스플레이 필터
ip.addr == 192.168.1.10
ip.src == 192.168.1.10 && tcp.port == 80
http   dns   icmp   arp
tcp.flags.syn == 1 && tcp.flags.ack == 0     # 연결 요청 SYN만

# 캡처 필터 (BPF)
host 192.168.1.10
port 80
net 10.0.0.0/8
tcp
```

### tcpdump 자주 쓰는 옵션
```bash
tcpdump -i eth0              # 인터페이스 지정
tcpdump -nn                  # 이름·포트 해석 안 함
tcpdump -c 10                # 10개만 캡처
tcpdump -w out.pcap          # 파일로 저장
tcpdump -r out.pcap          # 파일 읽기
tcpdump -X                   # 16진수 + ASCII 출력
tcpdump -nn port 80 and host 192.168.1.10
```

### TCP 플래그 16진수 값 (패킷 분석 단골)
| 플래그 | 값 |
|---|---|
| FIN | `0x01` |
| SYN | `0x02` |
| RST | `0x04` |
| PSH | `0x08` |
| ACK | `0x10` |
| URG | `0x20` |
| **SYN+ACK** | **`0x12`** |
| **PSH+ACK** | `0x18` |

### 16진수 IP 헤더 읽기 연습
```
45 00 00 3c 1c 46 40 00 40 06 b1 e6 c0 a8 00 68 c0 a8 00 01
```
| 바이트 | 필드 | 해석 |
|---|---|---|
| `45` | Version/IHL | 버전 **4**, 헤더 길이 5×4 = **20바이트** |
| `00` | TOS | 0 |
| `00 3c` | Total Length | 0x3c = **60바이트** |
| `1c 46` | Identification | 식별자 |
| `40 00` | Flags/Offset | **DF(단편화 금지)** 설정, 오프셋 0 |
| `40` | TTL | 0x40 = **64** |
| `06` | Protocol | **6 = TCP** |
| `b1 e6` | Checksum | (예시 값) |
| `c0 a8 00 68` | 출발지 IP | **192.168.0.104** |
| `c0 a8 00 01` | 목적지 IP | **192.168.0.1** |

> 16진수 변환: c0=192, a8=168, 00=0, 68=104. 0x40 = 4×16 = 64.

## 6. 최신 통신 기술 · 기기

| 기술 | 핵심 |
|---|---|
| **SDN** | **제어 평면과 데이터 평면 분리**, 중앙 컨트롤러가 정책 관리. OpenFlow(남향 API) |
| **NFV** | 네트워크 기능(방화벽·라우터 등)을 가상화해 일반 서버에서 실행 |
| **클라우드** | 서비스 모델 IaaS / PaaS / SaaS, 배포 모델 Public / Private / Hybrid (아래 표 참고) |
| **엣지 컴퓨팅** | 데이터 발생지 근처에서 처리해 지연 감소 |
| **IoT 통신** | Zigbee, Bluetooth LE, LoRa, NB-IoT |
| **5G** | 이론상 최대 20Gbps, 지연 1ms, 3대 특징 **eMBB(초고속) · URLLC(초저지연) · mMTC(대규모 연결)** |
| **Wi-Fi 6 / 6E / 7** | 802.11ax / 6GHz 대역 추가 / 802.11be |
| **VoIP** | 시그널링 **SIP(5060)**·H.323(1720), 음성 전송 **RTP(UDP)**, 코덱 G.711(64kbps)·G.729(8kbps) |
| **IPTV · 멀티캐스트** | IGMP로 그룹 관리 |
| **CDN** | 콘텐츠를 사용자 가까운 서버에 캐싱 |
| **가상화/컨테이너** | VM / Docker |

### 클라우드 서비스 모델 vs 배포 모델 (2026-3회 22번)
| 구분 | 종류 | 의미 |
|---|---|---|
| **배포 모델** (어디에 두고 누가 쓰는가) | **Public** | 공급자가 다수 이용자에게 제공 (AWS, Azure, GCP 등) |
| | **Private** | 한 조직 전용 (자체 구축 또는 전용 호스팅) |
| | **Hybrid** | Public + Private을 연동해 사용 |
| | Community | 공통 목적을 가진 조직들이 공유 |
| **서비스 모델** (무엇을 제공하는가) | **IaaS / PaaS / SaaS** | 인프라 / 개발 플랫폼 / 완성된 소프트웨어 |

> **on-premises(온프레미스)** 는 자체 설비에서 직접 운영하는 전통 방식으로, 클라우드 **배포 모델에 포함되지 않습니다** (기출 22번 정답).

### 클라우드 컴퓨팅의 특징 — NIST 5가지 (2026-1회 24번)
| 특징 | 설명 |
|---|---|
| **주문형 셀프서비스** | 이용자가 필요한 만큼 서버·네트워크·저장장치 등을 직접 할당 |
| 광범위한 네트워크 접근 | 다양한 단말에서 네트워크로 접근 |
| **자원 풀링** | 물리·가상 자원을 풀로 묶어 요구에 따라 **동적 할당/재할당**, **다중 임차(multi-tenant)** 모델 |
| **빠른 탄력성** | 필요에 따라 자원을 신속히 확장·축소 |
| **측정 가능한 서비스** | 미터링으로 사용량을 측정해 자원 사용을 **자동 제어·최적화**, 쓴 만큼 과금 |

> 기출 1회 24번: ‘**단일 임차인(single-tenant)** 모델의 자원 풀’은 틀린 설명입니다. 다수 사용자가 자원을 공유하는 **다중 임차(multi-tenant)** 가 클라우드의 특징입니다.

### SDN vs NFV vs SDS 구분 (2026-3회 20·26번)
| 기술 | 핵심 | 키워드 |
|---|---|---|
| **SDN** | **제어 평면과 데이터 평면 분리**, 중앙 컨트롤러가 네트워크를 프로그래밍 | 컨트롤러, OpenFlow |
| **NFV** | 방화벽·라우터·로드 밸런서 같은 **네트워크 기능을 소프트웨어(VNF)로 구현**해 범용 서버에서 실행 | **VNF**, 유연한 배포·확장 |
| **SDS** | 스토리지를 소프트웨어로 정의·관리 (스토리지 가상화) | 스토리지 |

> SDN과 NFV는 서로 보완 관계지만 **정의는 다릅니다.** 기출 26번에서 ‘제어/데이터 평면 분리’는 NFV가 아니라 **SDN** 설명이었습니다(오답 보기).

### 무선 채널 (필기 기출 유형)
- 2.4GHz 대역: 채널 폭 **22MHz**, 채널 간격 5MHz → **서로 겹치지 않는 채널은 1·6·11** (한국은 1~13채널, 겹치지 않는 4채널 구성은 1·5·9·13)
- 주파수 대역이 **겹치는 채널은 간섭**이 발생
- 채널은 장비가 **자동 선택**하거나 관리자가 **수동 지정** 가능
- **무선 호스트는 AP와 통신할 때 반드시 특정 채널을 사용**
- 5GHz 대역은 겹치지 않는 채널이 많아 간섭이 적음

## 7. 운용기기 보충 — NIC · SCSI · 스토리지

### NIC (Network Interface Card)
- 1·2계층 장비, **고유 MAC 주소** 보유
- 속도·듀플렉스 자동 협상, **Teaming/Bonding**(여러 NIC 묶음), **Wake-on-LAN**, **PXE** 네트워크 부팅
- 확인: 윈도우 장치 관리자, 리눅스 `ethtool eth0`

### SCSI
| 항목 | 내용 |
|---|---|
| 방식 | 병렬 버스, 한 버스에 여러 장치를 **체인(Daisy chain)**으로 연결 |
| ID | **Narrow(8비트) = 0~7**, **Wide(16비트) = 0~15**. **ID 중복 불가** |
| 호스트 어댑터 ID | 보통 **7** |
| 종단 저항 | 체인 **양 끝에 터미네이터(종단 저항)** 필요 |
| 후속 | **SAS**(직렬, 핫스왑), **iSCSI**(SCSI 명령을 **TCP/IP**로, 포트 3260), **FC**(Fibre Channel) |

### 디스크 인터페이스
| 방식 | 특징 |
|---|---|
| PATA(IDE) | 병렬, 최대 133MB/s |
| **SATA** | 직렬, SATA III 6Gbps |
| **SAS** | 직렬 SCSI, 서버용, 12Gbps |
| **NVMe** | PCIe 기반 SSD, 초고속 |

### DAS · NAS · SAN (출제 단골)
| 구분 | **DAS** | **NAS** | **SAN** |
|---|---|---|---|
| 연결 | 서버에 **직접 연결** | **LAN(IP)** 으로 파일 공유 | **전용 고속망(FC/iSCSI)** |
| 접근 단위 | 블록 | **파일** (NFS/SMB) | **블록** |
| 공유 | 불가 | 가능 | 가능 (대규모) |
| 특징 | 단순·저렴 | 설치 쉬움, 파일 서버 | 고성능·고가용성 |

### UPS 방식
| 방식 | 특징 |
|---|---|
| Off-line(Standby) | 평상시 직접 공급, 정전 시 전환(순단 있음) |
| Line-interactive | 전압 보정 기능 |
| **On-line(이중 변환)** | 항상 인버터로 공급 → **가장 안정적, 무순단** |

## 8. 마무리 체크 문제

1. 이더넷 프레임의 최소·최대 크기는? → **64B / 1518B**
2. 1000BASE-T의 IEEE 표준은? → **802.3ab**
3. ATM 셀의 크기와 구성은? → **53바이트 (헤더 5 + 페이로드 48)**
4. ISDN BRI의 구성과 속도? → **2B+D, 144kbps**
5. T1과 E1의 속도? → **1.544Mbps / 2.048Mbps**
6. Frame Relay에서 가상회선을 식별하는 값? → **DLCI**
7. Frame Relay가 X.25보다 빠른 이유? → **2계층에서 동작하며 오류 제어를 생략**
8. ADSL이 "비대칭"인 이유? → **다운로드 속도가 업로드보다 빠름**
9. 한 광섬유에 여러 파장을 실어 보내는 기술? → **WDM/DWDM**
10. 음성 PCM에서 8kHz × 8비트의 결과? → **64kbps**
11. 이더넷 10Mbps에서 쓰는 선로 부호? → **Manchester**
12. 수평 배선의 최대 길이(영구 링크 + 패치)? → **90m + 10m = 100m**
13. 스위치 환경에서 패킷을 캡처하려면? → **포트 미러링(SPAN)**
14. `tcp.flags.syn == 1 && tcp.flags.ack == 0`의 의미? → **연결 요청(SYN) 패킷만 표시**
15. SYN+ACK 플래그의 16진수 값? → **0x12**
16. IP 헤더의 `06`은 어떤 프로토콜? → **TCP**
17. SDN의 핵심 특징? → **제어 평면과 데이터 평면 분리**
18. 5G의 3대 특징? → **eMBB, URLLC, mMTC**
19. 2.4GHz에서 겹치지 않는 채널 3개? → **1, 6, 11**
20. 병렬 SCSI(Narrow)의 ID 범위와 종단 저항 위치? → **0~7, 체인 양 끝**
21. 파일 단위 공유(LAN)와 블록 단위 전용망 스토리지? → **NAS / SAN**
22. 가장 안정적인 UPS 방식? → **On-line(이중 변환)**
