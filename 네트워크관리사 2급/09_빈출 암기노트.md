## 3. 최다 함정 10선

### ① 172.32는 사설 IP가 아니다
사설 B클래스는 **172.16 ~ 172.31**까지만.

### ② PC ↔ 라우터는 크로스 케이블
같은 종단 장비로 취급 → 다이렉트가 아니라 **크로스**.

### ③ X서버 = 모니터가 있는 쪽 (리눅스마스터와 공통)
일반 상식과 반대.

### ④ ARP Request는 브로드캐스트, Reply는 유니캐스트
방향을 바꿔 물어보면 함정.

### ⑤ ICMP 타입 8=Request, 0=Reply
숫자가 순서와 반대.

### ⑥ RIP는 거리벡터, OSPF는 링크상태
메트릭도 다름: **홉 수 vs Cost**.

### ⑦ 허브는 충돌 도메인을 나누지 못하고, 스위치는 나눈다
브로드캐스트 도메인은 **라우터만** 나눔.

### ⑧ NAT의 PAT/NAPT는 포트로 구분 (다:1)
Static NAT는 1:1, Dynamic NAT는 IP 풀에서 동적 할당.

### ⑨ 표준 ACL은 목적지에 가깝게, 확장 ACL은 출발지에 가깝게
반대로 알면 오답.

### ⑩ Cisco `no shutdown`을 빼먹으면 인터페이스 죽음
실기 최다 감점 원인.

## 9. 서술형 대비 — 짧은 답 정리

**Q. 스위치와 허브의 차이를 설명하시오.**
> 허브는 1계층 장비로 들어온 신호를 모든 포트에 그대로 전달(플러딩)하여 포트 간 대역폭을 공유하고 충돌 도메인이 하나로 묶인다. 스위치는 2계층 장비로 MAC 주소를 학습해 목적지 포트로만 전달하므로 포트별로 독립된 충돌 도메인을 가지며 전이중 통신이 가능하다.

**Q. 라우터가 브로드캐스트 도메인을 분리하는 이유와 원리를 설명하시오.**
> 라우터는 3계층 장비로 서로 다른 네트워크(IP 대역)를 연결하며, 브로드캐스트 프레임은 2계층에서만 전파되고 라우터를 통과하지 못하므로 자연히 브로드캐스트 도메인이 분리된다. 이를 통해 불필요한 트래픽 확산을 막고 네트워크 성능을 향상시킨다.

**Q. DHCP의 동작 과정을 설명하시오.**
> 클라이언트가 DISCOVER를 브로드캐스트로 전송해 DHCP 서버를 탐색하고, 서버는 사용 가능한 IP를 OFFER로 제안한다. 클라이언트는 REQUEST로 해당 IP의 사용을 요청하고, 서버가 ACK로 최종 승인하면 IP 임대가 완료된다(DORA).

**Q. RIP와 OSPF의 차이를 비교 설명하시오.**
> RIP는 거리 벡터 알고리즘으로 홉 수를 메트릭으로 사용하며 최대 15홉까지만 지원하고 30초마다 전체 라우팅 테이블을 교환해 수렴이 느리다. OSPF는 링크 상태 알고리즘으로 대역폭 기반 Cost를 메트릭으로 사용하며 다익스트라 알고리즘으로 최단 경로를 계산하고, 변경이 있을 때만 갱신해 수렴이 빠르며 대규모 네트워크에 적합하다.

**Q. NAT의 필요성과 PAT의 동작 방식을 설명하시오.**
> IPv4 주소 고갈 문제를 완화하고 내부 네트워크 구조를 외부에 숨기기 위해 사용한다. PAT(NAPT)는 여러 개의 내부 사설 IP가 하나의 공인 IP를 공유하도록 하며, 포트 번호를 이용해 각 세션을 구분하므로 다대일 매핑이 가능하다.

## 12. 개정 보강 — 실기·필기 추가 포인트 (2026-10-09)

### 실기 윈도우 서버 GUI 8대 영역 (→ 08번)
IP 설정(계산) · DNS(SOA·A·CNAME) · DHCP(범위·제외·예약·활성화) · FTP · IIS(바인딩·IP 제한·기본 문서·연결 제한) ·
사용자/그룹 · 로컬 보안 정책(임계값 3 · 잠금 60분) · 서비스(**시작 유형 ≠ 서비스 상태**)

### 케이블 판단 한 줄
A그룹(MDI) **PC·라우터·서버** / B그룹(MDI-X) **스위치·허브** → **다른 그룹 = 다이렉트, 같은 그룹 = 크로스**

### 라우터 기본 명령 추가
`secondary` IP · `ip default-gateway`(라우팅 꺼진 장비) · `ip default-network` · `encapsulation` · DHCP pool ·
`snmp-server community 이름 ro` · SSH(**호스트명 + 도메인 + RSA 키 + `transport input ssh`**)

### 단답형 추가
- IPSec: **AH(51) = 인증·무결성 / ESP(50) = 암호화**, SA는 단방향(SPI), 터널 모드 = VPN, IKE는 UDP 500
- WAF = 웹 공격(SQLi·XSS) 방어, IDS = 탐지, IPS = 탐지 + 차단
- `traceroute` = UDP / `tracert` = ICMP, 둘 다 **TTL 증가 + ICMP Time Exceeded(11)**
- `icmp_echo_ignore_all = 1` → ping 무시
- DAS(직접) / NAS(LAN 파일 공유) / SAN(전용망 블록)
- SCSI: 체인 **양 끝 종단 저항**, Narrow ID 0~7
- ATM 셀 **53B (5+48)** · ISDN BRI **144kbps** · T1 **1.544M** · E1 **2.048M**
- TCP 플래그 16진수: SYN `0x02` · **SYN+ACK `0x12`** · ACK `0x10` · FIN `0x01` · RST `0x04`
- IP 헤더의 프로토콜 필드 `06` = TCP, `11`(16진수) = UDP(17), `01` = ICMP
- 2.4GHz 겹치지 않는 채널: **1 · 6 · 11**

### 2026-3회 기출에서 보강한 포인트 (→ 해당 파일 참고)
- **IPv6 표기(RFC 5952)**: 선행 0 생략 · 0 필드 하나는 `0` · `::`은 한 번만, 2개 이상 연속된 0 중 **가장 긴 구간**(같으면 **왼쪽**) · 소문자 (02번)
- **DHCP 할당 방식**: 수동 · 자동 · 동적 — ‘우선순위 할당’은 없음 (02번)
- **클라우드 배포 모델**: Public · Private · Hybrid · (Community) — **on-premises는 아님** (10번)
- **SDN(제어/데이터 분리) vs NFV(VNF) vs SDS(스토리지)** (10번)
- **PowerShell**: cmdlet 동사-명사 · **DOS 명령 사용 가능** · **대소문자 구분 안 함** · .ps1 (04번)
- **Hyper-V**: **검사점(Checkpoint)** = 특정 시점 저장·복원 / 내보내기 = 복사·이전 (04번)
- **AD 트러스트**: 같은 포리스트 = **양방향 전이** 자동 / 외부 = 비전이 (04번)
- **Windows DHCP**: 지연(Subnet delay)은 **ms**, 예약 유형 DHCP·BOOTP·둘 다 (08번)
- **IIS**: 홈 디렉터리는 **임의 경로 가능**, 가상 디렉터리 = 별칭 + 실제 경로 (08번)
- **L4 스위치 = 4계층(포트)**, HTTP 내용 기반은 L7 (05번)
- **UDP 헤더 4필드**: 출발지 포트 · 목적지 포트 · 길이 · 체크섬 — **확인 응답 번호 없음** (02번)
- **ICMP 17/18** = Address Mask Request/Reply, **타입 3 = Destination Unreachable** (02번)
- **프로토콜 기능 10가지**: 캡슐화 = 헤더·트레일러 부가 (01번)
- **1000BASE-SX / BX** (NX·AX는 없음) (01번)
- **`ps -ef`**: UID · PID · PPID · C · STIME · TTY · TIME · CMD — **PID와 PPID 혼동 주의** (리눅스마스터 05번)
- **Distance Vector = RIP·IGRP**, OSPF는 링크 상태 (02번)

### 2026-1·2회 기출에서 보강한 포인트
- **SSH**: 암호화·무결성·공개키 인증, **여러 OS에서 사용 가능**, 포트 22 (11번)
- **ICMP**: 오류 보고 + 질의 메시지 / **TTL은 IP 헤더 필드** (02번)
- **흐름 제어**: Stop-and-Wait · Sliding Window · XON/XOFF — **Loop/Echo는 오류 검출** (01번)
- **전송 장애**: 감쇠 · **지연(위상) 왜곡** · 잡음(누화·충격성) (01번)
- **클라우드 특징**: 셀프서비스 · 접근성 · 자원 풀링(**다중 임차**) · 탄력성 · 측정 가능 (10번)
- **VTP 모드**: Server · Client · Transparent (**interface mode 없음**) (05번)
- **BIND**: `allow-query`(허용 대역) · `listen-on port 53` · `masterfile-format text` (04번)
- **Apache**: `LimitRequestBody` = POST 본문 크기 제한 (04번)
- **ping**: 리눅스 `rtt min/avg/max/mdev`(**평균은 두 번째 값**), `ttl`은 남은 홉 수 (08번)
- **netstat -t = TCP** (시간 정보 아님), `-p` PID, `-r` 라우팅 (08번)
- **Hyper-V**: VHD를 **실행 중 다른 저장소로 이동 가능**, 복제 가능, 자원 사용률 ↑ / **Containers = 커널 공유 경량 격리** (04번)
- **리소스 모니터(resmon)** = 실시간 CPU·메모리·디스크·네트워크 (04번)
- **DNS TTL** = 캐시 유지 시간. 짧으면 반영 빠름·부하 ↑, 길면 부하 ↓·갱신 지연 (02번)
- **IIS 로그**: 위치 변경 가능, W3C(기본) 외 형식도 지원, 최대 크기 도달 시 새 파일 (08번)
- **로드 밸런서**: Round Robin(순차) · Least Connection · Weighted · IP Hash + **Health Check** (05번)
- **IPv6 Hop Limit** = 생존 기간(IPv4 TTL 대응) (02번)
- **TCP 헤더**: Flags 9비트(현재 정의) · **Checksum 16비트** (02번)
- **OSPF**: Hello 패킷 · **동일 비용 다중 경로(ECMP)** · IPv4=v2 / IPv6=v3 (02번)
- **WDM**: 파장 축 다중화 · 채널별 다른 프로토콜 수용 · 광증폭기 장거리 · 선로 증설 없이 확장 (10번)
- **무선 메시**: 각 노드가 트래픽을 릴레이, 유선 없이 확장 (01번)
- **DHCP Failover**: Load Balance / Hot Standby, **MCLT = 파트너가 임대를 임시 갱신할 수 있는 최대 시간** (08번)
- **FTP 서버 설치**: 서버 관리자 → 역할 및 기능 추가 → 웹 서버(IIS) → FTP 서버, **IIS FTP만으로 SFTP 불가** (08번)
