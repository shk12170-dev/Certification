## 1. 동적 라우팅 설정 (OSPF · EIGRP)

### OSPF
```cisco
R1(config)# router ospf 1                              ! 1 = 프로세스 ID(로컬 의미)
R1(config-router)# network 192.168.1.0 0.0.0.255 area 0
R1(config-router)# network 10.0.0.0 0.0.0.3 area 0
R1(config-router)# router-id 1.1.1.1
R1(config-router)# exit
```
> ⚠️ **OSPF는 서브넷마스크가 아니라 와일드카드 마스크**를 씁니다.
> **와일드카드 마스크 = 255.255.255.255 - 서브넷마스크**

| 서브넷마스크 | 와일드카드 마스크 |
|---|---|
| 255.255.255.0 | **0.0.0.255** |
| 255.255.255.192 (/26) | 0.0.0.63 |
| 255.255.255.252 (/30) | **0.0.0.3** |
| 255.255.0.0 | 0.0.255.255 |
| 255.0.0.0 | 0.255.255.255 |

### EIGRP
```cisco
R1(config)# router eigrp 100               ! 100 = AS 번호(모든 라우터 동일해야 함)
R1(config-router)# network 192.168.1.0
R1(config-router)# no auto-summary
```

## 스위치 설정 (VLAN · 트렁크 · 포트 보안, 1급 수준)

```cisco
Switch> enable
Switch# configure terminal
Switch(config)# hostname SW1

! 관리 IP 설정 (스위치는 VLAN 인터페이스에 IP 부여)
SW1(config)# interface vlan 1
SW1(config-if)# ip address 192.168.1.250 255.255.255.0
SW1(config-if)# no shutdown
SW1(config-if)# exit
SW1(config)# ip default-gateway 192.168.1.1     ! ★ 스위치의 기본 게이트웨이

! VLAN 생성
SW1(config)# vlan 10
SW1(config-vlan)# name SALES
SW1(config-vlan)# exit
SW1(config)# vlan 20
SW1(config-vlan)# name IT
SW1(config-vlan)# exit

! 포트를 VLAN에 할당 (Access 포트)
SW1(config)# interface fa0/1
SW1(config-if)# switchport mode access
SW1(config-if)# switchport access vlan 10
SW1(config-if)# exit

! 여러 포트 동시 설정
SW1(config)# interface range fa0/1 - 10
SW1(config-if-range)# switchport mode access
SW1(config-if-range)# switchport access vlan 10

! 트렁크 포트 설정
SW1(config)# interface gi0/1
SW1(config-if)# switchport mode trunk
SW1(config-if)# switchport trunk encapsulation dot1q   ! 802.1Q
SW1(config-if)# switchport trunk allowed vlan 10,20
SW1(config-if)# exit

! 포트 보안
SW1(config)# interface fa0/2
SW1(config-if)# switchport port-security
SW1(config-if)# switchport port-security maximum 1
SW1(config-if)# switchport port-security violation shutdown
SW1(config-if)# switchport port-security mac-address sticky

! 속도·듀플렉스
SW1(config-if)# speed 100
SW1(config-if)# duplex full
```

### 스위치 확인 명령
```cisco
SW1# show vlan brief              ! ★ VLAN 목록과 소속 포트
SW1# show interfaces trunk        ! 트렁크 상태
SW1# show mac address-table       ! ★ MAC 주소 테이블
SW1# show port-security
SW1# show spanning-tree           ! STP 상태, 루트 브리지 확인
```

## Router-on-a-Stick (VLAN 간 라우팅)

```cisco
! 라우터 쪽: 서브인터페이스 생성
R1(config)# interface fa0/0
R1(config-if)# no shutdown
R1(config-if)# exit

R1(config)# interface fa0/0.10
R1(config-subif)# encapsulation dot1q 10
R1(config-subif)# ip address 192.168.10.1 255.255.255.0
R1(config-subif)# exit

R1(config)# interface fa0/0.20
R1(config-subif)# encapsulation dot1q 20
R1(config-subif)# ip address 192.168.20.1 255.255.255.0
R1(config-subif)# exit

! 스위치 쪽: 라우터 연결 포트를 트렁크로
SW1(config)# interface fa0/24
SW1(config-if)# switchport mode trunk
```

## ACL (접근 제어 목록)

### 표준 ACL (번호 1~99) — **출발지 IP만** 검사
```cisco
R1(config)# access-list 10 deny 192.168.1.10 0.0.0.0
R1(config)# access-list 10 permit any
R1(config)# interface fa0/1
R1(config-if)# ip access-group 10 out
```

### 확장 ACL (번호 100~199) — 출발지·목적지·프로토콜·포트
```cisco
R1(config)# access-list 100 deny tcp 192.168.1.0 0.0.0.255 any eq 80
R1(config)# access-list 100 permit ip any any
R1(config)# interface fa0/0
R1(config-if)# ip access-group 100 in
```

### 핵심 규칙 (출제 포인트)
| 규칙 | 내용 |
|---|---|
| **암묵적 거부** | ACL 끝에는 보이지 않는 **`deny any`**가 있음 → 반드시 `permit` 문장 필요 |
| 순차 처리 | **위에서부터** 일치하는 첫 문장만 적용 |
| 적용 위치 | **표준 ACL = 목적지에 가깝게**, **확장 ACL = 출발지에 가깝게** |
| 인터페이스당 | 방향(in/out)별 **1개씩만** 적용 가능 |
| 와일드카드 | `0.0.0.0` = host 하나, `255.255.255.255` = any |

```cisco
R1# show access-lists
```
