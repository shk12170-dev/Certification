| 항목 | 내용 | 검증 |
|---|---|---|
| 주관 | (사)한국정보통신자격협회(ICQA), 국가공인 민간자격 | ✅ |
| 필기 과목 | ① 네트워크 일반 ② TCP/IP ③ NOS ④ 네트워크 운용기기 | ✅ |
| 필기 형식 | 4지선다 객관식, 100점 만점 60점 이상 합격 | ✅ |
| 필기 문항/시간 | 50문항 / 50분 (일부 자료는 40문항 표기) | ❓ |
| 실기 | 필기 합격 후 **2년 내** 응시, CBT 방식 | ✅ |
| 실기 내용 | 장비 설정·네트워크 구성·서버 설정 등 실무형 (상세 유형 미확인) | ❓ |
| 시행 횟수 | 연 4회 정기 시행 | ✅ |
| 2026 3회 필기 | 2026-08-02 로 표기된 자료 존재 (이미 지남) | ❓ |
| 2026 4회 일정 | 미확인 → 공식 공지 확인 | ❓ |
| 출제기준 변경 | **2025년 8월부터 변경된 출제기준 적용** (교재 광고·검색 요약 기준, 세부 항목 미확인) | ❓ |
| 2026 실기 경향 | 정보보안(NGFW 등) 신유형 다수 출제, 기존 교재 외 내용 포함이라는 후기 | ❓ |
| 학습 팁 | 최근 2년치(8회분) 기출은 최소 1회 풀이 권장 | ❓ |

과목별 출제 비중(대략): 네트워크 일반 / TCP/IP / NOS / 운용기기 각 약 25% 균등 (실제 문항 배분은 확인 필요).

## 2. 리눅스마스터 2급

| 항목 | 내용 | 검증 |
|---|---|---|
| 주관 | 한국정보통신진흥협회(KAIT) | ✅ |
| 구성 | 1차·2차 모두 필기(객관식). 2급은 실기 없음 | ✅ |
| 1차 | 리눅스 일반 위주, 50문항 사지선다 | ❓ |
| 2차 | 80문항 사지선다 (리눅스 운영·관리 48, 리눅스 활용 32) | ❓ |
| 합격 기준 | 각 차수 100점 만점 60점 이상 | ✅ |
| 출제 과목 | 리눅스 일반 / 리눅스 운영·관리 / 리눅스 활용 (자료에 따라 "일반·활용" 2과목으로도 표기) | ✅/❓ |
| 시험 방식 | 2026년 2회차부터 정해진 시간 시작 **온라인 감독 시험**(구 오픈북 방식 폐지), 스마트폰 카메라 + 웹캠(마이크) 필수 | ❓ |
| 1차 시간 | 60분 (50문항 중 30문항 이상) | ❓ |
| 2차 | 시험장에서 필기 응시 | ❓ |
| 출제 기준 환경 | CentOS 대신 **Rocky Linux 8.x** 기준이라는 교재 자료 → `content/linux-master-2/04-rocky8-update.md` | ❓ |
| 시행 횟수 | 연 2~5회로 자료마다 상이 | ❓ |
| 하반기 일정 | 미확인 → 공식 공지 확인 | ❓ |

## 3. 하반기 시험 대비 제안 일정 (역산)
1. 공식 사이트에서 하반기 남은 회차 날짜·접수기간 확인
2. 시험일 D-4주: 이론 1회독 (`content/` 노트)
3. D-2주: 기출/CBT 모의고사 회차별 풀이, 오답노트
4. D-1주: 암기 요약(포트번호, 명령어, 주소 표) + 시험 환경 점검
