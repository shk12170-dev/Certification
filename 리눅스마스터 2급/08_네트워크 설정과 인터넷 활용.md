## 2. 네트워크 토폴로지와 LAN 기술

### 토폴로지
| 형태 | 특징 |
|---|---|
| **버스(Bus)** | 하나의 케이블 공유. 설치 쉬움, 케이블 장애 시 전체 마비 |
| **스타(Star)** | 중앙 장비(허브/스위치) 연결. **현재 가장 일반적**. 중앙 고장 시 전체 마비 |
| **링(Ring)** | 원형 연결. Token Ring, FDDI |
| **메시(Mesh)** | 모든 노드 상호 연결. 안정성 최고, 비용 높음 |
| **트리(Tree)** | 계층적 스타 확장 |

### LAN 접근 제어 방식
| 방식 | 설명 |
|---|---|
| **CSMA/CD** | **이더넷(유선)**. 충돌 탐지 후 재전송 |
| **CSMA/CA** | **무선랜(Wi-Fi)**. 충돌 회피 |
| **Token Passing** | 토큰을 가진 노드만 전송 (Token Ring) |

### 네트워크 규모별 분류
LAN(근거리) → **MAN**(도시권) → WAN(광역)
- VLAN: 논리적 LAN 분할
- VPN: 공용망을 통한 사설망 구성 (터널링)

### 무선랜 규격
| 규격 | 주파수 | 최대 속도 |
|---|---|---|
| 802.11b | 2.4GHz | 11Mbps |
| 802.11a | 5GHz | 54Mbps |
| 802.11g | 2.4GHz | 54Mbps |
| 802.11n (Wi-Fi 4) | 2.4/5GHz | 600Mbps |
| 802.11ac (Wi-Fi 5) | 5GHz | 6.9Gbps |
| 802.11ax (Wi-Fi 6) | 2.4/5GHz | 9.6Gbps |

무선 보안: WEP(취약) → WPA → **WPA2(AES/CCMP)** → WPA3

## 3. 리눅스 네트워크 설정 파일 (RHEL 계열 기준)

### `/etc/sysconfig/network-scripts/ifcfg-eth0`
```bash
DEVICE=eth0                 # 장치명
NAME=eth0
TYPE=Ethernet
ONBOOT=yes                  # 부팅 시 활성화 ★
BOOTPROTO=static            # static | dhcp | none ★
IPADDR=192.168.1.100        # IP 주소
NETMASK=255.255.255.0       # 서브넷마스크
PREFIX=24                   # (NETMASK 대체)
GATEWAY=192.168.1.1         # 기본 게이트웨이
DNS1=8.8.8.8
DNS2=168.126.63.1
HWADDR=00:0C:29:XX:XX:XX    # MAC 주소
```

| 항목 | 의미 |
|---|---|
| `ONBOOT=yes` | 부팅 시 자동 활성화 |
| `BOOTPROTO=static` | 고정 IP |
| `BOOTPROTO=dhcp` | DHCP 자동 할당 |

### 그 밖의 파일
| 파일 | 역할 |
|---|---|
| `/etc/sysconfig/network` | 호스트명, 기본 게이트웨이(구 방식) |
| `/etc/hostname` | 호스트명 |
| `/etc/hosts` | 호스트명 ↔ IP 수동 매핑. **DNS보다 먼저 참조** |
| `/etc/resolv.conf` | DNS 서버 지정 (`nameserver`, `search`, `domain`) |
| `/etc/nsswitch.conf` | 이름 해석 순서 (`hosts: files dns`) |
| `/etc/services` | 서비스명 ↔ 포트 |
| `/etc/protocols` | 프로토콜명 ↔ 번호 |
| `/etc/network/interfaces` | **Debian/Ubuntu 계열** NIC 설정 |
| `/etc/netplan/*.yaml` | 최신 Ubuntu 네트워크 설정 |

### `/etc/resolv.conf` 예
```
nameserver 8.8.8.8
nameserver 168.126.63.1
search example.com
domain example.com
```
> nameserver는 최대 3개까지 유효합니다.

### 서비스 재시작
```bash
systemctl restart network          # RHEL 7
systemctl restart NetworkManager   # RHEL 7/8+
nmcli connection reload
ifdown eth0 && ifup eth0
```

## 4. 네트워크 설정·확인 명령

```bash
# IP 확인·설정
ifconfig                                  # 전체 인터페이스
ifconfig eth0                             # 특정 인터페이스
ifconfig eth0 192.168.1.100 netmask 255.255.255.0 up   # 임시 설정
ifconfig eth0 up / down                   # 활성/비활성
ifconfig eth0 mtu 1400                    # MTU 변경
ip addr show                              # ★ 신 방식
ip addr add 192.168.1.100/24 dev eth0
ip addr del 192.168.1.100/24 dev eth0
ip link set eth0 up / down
ip -s link                                # 통계 포함

# 라우팅
route -n                                  # 라우팅 테이블 (숫자로) ★
route add default gw 192.168.1.1          # 기본 게이트웨이 추가
route add -net 10.0.0.0/8 gw 192.168.1.254
route del default gw 192.168.1.1
ip route show                             # ★ 신 방식
ip route add default via 192.168.1.1
netstat -rn                               # 라우팅 테이블

# 연결 진단
ping 8.8.8.8
ping -c 4 8.8.8.8                         # 4회만 (count) ★
ping -i 2 host                            # 2초 간격
ping -s 1000 host                         # 패킷 크기 지정
traceroute 8.8.8.8                        # 경로 추적 ★
tracepath 8.8.8.8
mtr 8.8.8.8                               # 실시간 경로 + 손실률

# 소켓·포트
netstat -an                               # 전체 연결
netstat -antp                             # ★ TCP + 숫자 + 프로세스
netstat -tulnp                            # ★ LISTEN 중인 포트 확인
netstat -i                                # 인터페이스 통계
netstat -s                                # 프로토콜별 통계
ss -antp                                  # ★ netstat 후속
ss -tulnp
lsof -i :80                               # 80번 포트 사용 프로세스

# DNS 조회
nslookup www.google.com
dig www.google.com                        # 상세 조회 ★
dig @8.8.8.8 example.com MX               # 특정 서버·레코드 지정
dig -x 8.8.8.8                            # 역방향 조회
host www.google.com
hostname                                  # 호스트명
hostnamectl set-hostname server1          # 호스트명 영구 변경 ★

# ARP
arp -a                                    # ARP 캐시
arp -d 192.168.1.1                        # 항목 삭제
ip neigh show                             # 신 방식

# NIC 상태
ethtool eth0                              # 속도·듀플렉스·링크 상태 ★
ethtool -s eth0 speed 100 duplex full
mii-tool eth0                             # 링크 상태(구)

# nmcli (NetworkManager CLI)
nmcli device status
nmcli connection show
nmcli connection up eth0
nmcli con mod eth0 ipv4.addresses 192.168.1.100/24
nmcli con mod eth0 ipv4.gateway 192.168.1.1
nmcli con mod eth0 ipv4.method manual

# 파일 전송·다운로드
wget http://example.com/file.tar.gz       # 다운로드 ★
wget -c URL                               # 이어받기
wget -r URL                               # 재귀적(사이트 미러)
curl -O URL                               # 다운로드
curl -I URL                               # 헤더만 확인
scp file user@host:/path                  # SSH 기반 복사 ★
scp -r dir user@host:/path                # 디렉터리
scp user@host:/path/file .                # 가져오기
sftp user@host                            # 대화형 보안 FTP
rsync -avz src/ user@host:dst/            # 동기화

# 원격 접속
ssh user@host                             # ★
ssh -p 2222 user@host                     # 포트 지정
ssh -i key.pem user@host                  # 키 파일 지정
ssh-keygen -t rsa -b 4096                 # 키 쌍 생성 ★
ssh-copy-id user@host                     # 공개키 전송
telnet host 80                            # 포트 연결 테스트
nc -zv host 80                            # 포트 스캔·테스트

# 방화벽
firewall-cmd --state
firewall-cmd --list-all
firewall-cmd --permanent --add-port=80/tcp     # ★
firewall-cmd --permanent --add-service=http
firewall-cmd --reload
iptables -L -n                                 # 규칙 목록
iptables -A INPUT -p tcp --dport 22 -j ACCEPT
```

### 파일 공유 서비스 비교 (출제 단골)
| 구분 | **NFS** | **Samba (SMB/CIFS)** |
|---|---|---|
| 용도 | **UNIX/Linux ↔ UNIX/Linux** | **Linux ↔ Windows** |
| 설정 파일 | `/etc/exports` | `/etc/samba/smb.conf` |
| 데몬 | `nfs`, `rpcbind`(portmap) | `smbd`, `nmbd` |
| 포트 | 2049 | 137~139, 445 |
| 마운트 | `mount -t nfs host:/share /mnt` | `mount -t cifs //host/share /mnt` |

```bash
# NFS 서버
vi /etc/exports
/data  192.168.1.0/24(rw,sync,no_root_squash)
exportfs -ra              # 설정 반영
showmount -e host         # 공개 목록 확인

# Samba
smbclient -L //host       # 공유 목록
smbpasswd -a user1        # Samba 계정 추가
testparm                  # smb.conf 문법 검사
```

## 6. 인터넷 서비스 프로토콜 정리

| 프로토콜 | 용도 | 포트 |
|---|---|---|
| HTTP / HTTPS | 웹 | 80 / 443 |
| FTP | 파일 전송 (능동/수동 모드) | 21(제어) / 20(데이터) |
| **SFTP / SCP** | SSH 기반 보안 전송 | 22 |
| TFTP | 간이 파일 전송(UDP) | 69 |
| SMTP | 메일 발신 | 25 |
| POP3 | 메일 수신(다운로드 후 서버에서 삭제) | 110 |
| IMAP | 메일 수신(서버에 보관, 다중 기기) | 143 |
| Telnet | 원격 접속 (**평문 — 보안 취약**) | 23 |
| SSH | 원격 접속 (**암호화**) | 22 |
| DNS | 이름 해석 | 53 |
| DHCP | IP 자동 할당 | 67/68 |
| SNMP | 네트워크 관리 | 161/162 |
| NTP | 시간 동기화 | 123 |
| LDAP | 디렉터리 | 389 |
| RDP | 윈도우 원격데스크톱 | 3389 |
| VNC | 원격 데스크톱 | 5900+ |

### FTP 능동(Active) vs 수동(Passive) 모드
| 모드 | 데이터 연결 방향 |
|---|---|
| **Active** | **서버 → 클라이언트** (서버 20번 포트에서 연결 시도). 클라이언트 방화벽에 막히기 쉬움 |
| **Passive** | **클라이언트 → 서버** (서버가 임의 포트를 알려줌). 방화벽 환경에 유리 |

### POP3 vs IMAP
| 구분 | POP3 | IMAP |
|---|---|---|
| 메일 보관 | 클라이언트로 다운로드 | **서버에 보관** |
| 다중 기기 | 부적합 | **적합** |
| 포트 | 110 | 143 |

## 7. DHCP 동작 과정 (순서 암기 ★)

```
1. DHCP DISCOVER  — 클라이언트 → 브로드캐스트로 서버 탐색
2. DHCP OFFER     — 서버 → IP 제안
3. DHCP REQUEST   — 클라이언트 → 해당 IP 사용 요청
4. DHCP ACK       — 서버 → 최종 승인
```
암기: **DORA** (Discover - Offer - Request - Ack)

- DHCP 실패 시: **169.254.x.x (APIPA)** 자동 할당
- 임대 갱신: 임대 기간의 50% 시점에 갱신 시도(RENEW), 87.5%에 REBIND
- 리눅스 클라이언트: `dhclient`, `dhclient -r`(반납)

## 9. 보안 기초

| 용어 | 설명 |
|---|---|
| **방화벽(Firewall)** | 패킷 필터링. `iptables`, `nftables`, `firewalld` |
| **IDS** | 침입 **탐지** 시스템 (탐지·경고만) |
| **IPS** | 침입 **방지** 시스템 (차단까지) |
| **SELinux** | 강제 접근 제어(MAC). 모드: enforcing / permissive / disabled (`getenforce`, `setenforce 0`) |
| **TCP Wrapper** | 서비스 접근 제어. `/etc/hosts.allow`, `/etc/hosts.deny` ★ |
| **PAM** | 인증 모듈. `/etc/pam.d/` |
| **DoS / DDoS** | 서비스 거부 공격 |
| **스니핑** | 패킷 도청 (`tcpdump`, `wireshark`) |
| **스푸핑** | 주소 위장 (IP/ARP/DNS 스푸핑) |
| **SetUID 점검** | `find / -perm -4000` |

### TCP Wrapper 규칙 (출제 포인트)
```
# /etc/hosts.allow
sshd : 192.168.1.

# /etc/hosts.deny
ALL : ALL
```
> **`hosts.allow`를 먼저 확인하고, 그다음 `hosts.deny`를 확인합니다.** 둘 다 없으면 허용.

### SELinux 명령
```bash
getenforce                  # 현재 모드
setenforce 0                # permissive로 임시 전환
setenforce 1                # enforcing
sestatus                    # 상태 상세
# 영구 변경: /etc/selinux/config 의 SELINUX= 값 수정
```

## 10. 마무리 체크 문제

1. 부팅 시 NIC를 자동 활성화하는 ifcfg 항목? → **`ONBOOT=yes`**
2. 고정 IP를 쓰려면 `BOOTPROTO` 값? → **`static`**
3. DNS 서버를 지정하는 파일? → **`/etc/resolv.conf`**
4. `/etc/hosts`와 DNS 중 먼저 참조되는 것? → **`/etc/hosts`**
5. LISTEN 중인 포트를 확인하는 명령? → `netstat -tulnp` / `ss -tulnp`
6. 기본 게이트웨이를 확인하는 명령 2가지? → `route -n`, `ip route`
7. ping을 4회만 보내는 옵션? → `-c 4`
8. NIC 속도·듀플렉스를 확인하는 명령? → `ethtool`
9. 호스트명을 영구히 바꾸는 명령? → `hostnamectl set-hostname`
10. NFS의 설정 파일? → **`/etc/exports`**
11. Samba의 설정 파일과 용도? → **`/etc/samba/smb.conf`**, 윈도우와 파일 공유
12. SSH 서버 설정 파일과 root 로그인 차단 항목? → `/etc/ssh/sshd_config`, `PermitRootLogin no`
13. DHCP 4단계 순서? → **Discover → Offer → Request → Ack (DORA)**
14. FTP 수동 모드의 데이터 연결 방향? → **클라이언트 → 서버**
15. 메일을 서버에 보관해 여러 기기에서 보기 적합한 프로토콜? → **IMAP (143)**
16. 유선 이더넷과 무선랜의 접근 제어 방식? → **CSMA/CD / CSMA/CA**
17. TCP Wrapper의 두 설정 파일과 확인 순서? → `hosts.allow` → `hosts.deny`
18. SELinux 모드 3가지? → enforcing / permissive / disabled
19. IaaS·PaaS·SaaS 중 인프라만 제공하는 모델? → **IaaS**
20. 컨테이너와 가상머신의 핵심 차이? → **컨테이너는 호스트 커널을 공유**하므로 가볍고 빠름
