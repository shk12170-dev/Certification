# 리눅스마스터 2급 — 시험 개요 · 일정 · 합격 전략

## 1. 기본 정보

| 항목 | 내용 |
|---|---|
| 시행기관 | 한국정보통신진흥협회(KAIT) — https://www.ihd.or.kr |
| 자격 종류 | 국가공인 민간자격 |
| 응시자격 | **제한 없음** (누구나) |
| 시험 횟수 | 연 4회 |
| 학점 인정 | 5학점 |
| 검정 구분 | 1차 시험 + 2차 시험 (둘 다 합격해야 취득) |

## 2. 시험 구성 — 가장 많이 헷갈리는 부분

| 구분 | 1차 시험 | 2차 시험 |
|---|---|---|
| 방식 | **온라인 CBT** | **오프라인 필기(PBT)** |
| 문항 수 | 50문항 | **80문항** |
| 문제 유형 | 객관식 4지선다 | **객관식 4지선다** |
| 시험 시간 | 60분 | 100분 (14:00~15:40) |
| 배점 | 100점 | 100점 |
| 합격 기준 | 60점 이상 (30문항 이상) | 60점 이상 + **과목당 40% 미만 과락** |
| 결과 확인 | 응시 직후 즉시 | 지정 발표일 |

> 🔴 **핵심**: **2급의 2차 시험은 실습(실기)이 아니라 객관식 필기입니다.** 터미널에서 직접 작업하는 실습 시험은 리눅스마스터 **1급** 2차입니다. "2급도 실기 실습이 있다"는 잘못된 정보에 시간 낭비하지 마세요.

## 3. 출제 과목 및 범위

### 1차 시험 (50문항)
| 과목 | 주요 내용 |
|---|---|
| 리눅스 일반 | 리눅스 개요, 역사, 라이선스, 배포판, 디렉터리 구조 |
| 리눅스 운영 및 관리 | 설치, 기본 명령어, 파일시스템, 권한, 프로세스, Shell, 에디터, 패키지 |
| 리눅스 활용 | X 윈도, 인터넷 활용, 네트워크 설정, 응용 분야 |

### 2차 시험 (80문항) — 과목 비중이 중요
| 과목 | 문항 수 | 비중 | 과락선 |
|---|---|---|---|
| **1과목: 리눅스 운영 및 관리** | 48문항 | 60% | 19.2점 미만 과락 |
| **2과목: 리눅스 활용** | 32문항 | 40% | 12.8점 미만 과락 |

> 1과목 48문항 중 **터미널 명령어 문제가 8할 이상**입니다. 명령어와 옵션 암기가 곧 점수입니다.
> 2과목은 네트워크·응용 분야여서 범위가 넓고 체감 난이도가 높습니다. **과락 방지를 위해 2과목을 절대 버리지 마세요.**

## 4. 2026년 시험 일정 (하반기 = 2604회)

| 회차 | 1차 접수 | 1차 시험 | 2차 접수 | 2차 시험 | 최종 발표 |
|---|---|---|---|---|---|
| 2603 | 07.27~08.05 | 07.28~08.06 | 07.28~08.07 | 09.12 | 10.09 |
| **2604** ★ | **10.26~11.04** | **10.27~11.05** | **10.27~11.06** | **12.12** | **12.31** |

- 1차는 접수 기간 중 원하는 날짜/시간을 선택해 온라인으로 응시합니다.
- 2026년 2회차부터 1차가 "정해진 시간에 시작하는 온라인 시험" 방식으로 변경되었습니다.
- **2차 접수가 1차 시험과 거의 동시에 진행됩니다(10.27~11.06).** 1차 합격 후 반드시 기간 내 2차를 접수하세요. 놓치면 다음 회차까지 기다려야 합니다.
- 일정은 접수 전 https://www.ihd.or.kr/guidecert1.do 에서 최종 확인.

## 5. 합격 전략

### 학습 순서 (권장)
```
01_리눅스 일반          ← 가볍게, 암기 위주 (2일)
02_리눅스 설치          ← 파티션/부트로더 (2일)
03_기본 명령어          ← 여기가 핵심, 시간 많이 투자 (5일)
04_파일시스템과 권한관리 ← 퍼미션 계산 필수 (3일)
05_쉘과 프로세스 관리    ← 3일
06_에디터와 소프트웨어 설치 ← vi + rpm/yum/apt (3일)
07_X윈도와 시스템 관리   ← 2일
08_네트워크 설정과 인터넷 활용 ← 2과목 과락 방지 핵심 (4일)
09_명령어 치트시트       ← 매일 반복
10_빈출 암기노트        ← 시험 전날 1회독
```

### 실천 수칙
1. **명령어는 눈으로 읽지 말고 직접 타이핑하세요.** WSL2 또는 VirtualBox + Rocky Linux를 깔고 한 번씩 실행해보면 옵션이 머리에 박힙니다.
   ```bash
   wsl --install -d Ubuntu
   ```
2. **기출 회독이 왕도입니다.** 문제은행 경향이 강해 최근 2~3년 기출에서 유사 문제가 많이 나옵니다. https://www.comcbt.com/xe/r2 에서 무료로 회차별 풀이 가능.
3. **옵션 문자를 구분해서 외우세요.** `tar -zxvf` vs `-jxvf`, `ps -ef` vs `ps aux`, `chmod 755` vs `chmod u+x` 같은 혼동 포인트가 정답을 갈라놓습니다.
4. **2차는 과락을 먼저 막으세요.** 1과목 만점을 노리기보다 2과목에서 13점 이상을 확실히 확보하는 편이 합격에 가깝습니다.
5. **합격률이 20~30%대로 떨어지는 회차도 있습니다.** 벼락치기가 통하는 시험이라는 후기도 많지만, 그건 명령어 암기량이 이미 있는 경우입니다. 2주는 확보하세요.
