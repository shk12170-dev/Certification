# 07. X 윈도와 시스템 관리

## 1. X 윈도 시스템 개요

**X 윈도(X Window System)** = 유닉스/리눅스의 **네트워크 기반 GUI 시스템**

| 항목 | 내용 |
|---|---|
| 개발 | 1984년 MIT (Athena 프로젝트) |
| 현재 버전 | X11 (X11R7 등) |
| 라이선스 | **MIT 라이선스** |
| 구현체 | **XFree86** → **X.org (Xorg)** 로 주류 이동 |
| 최신 대안 | **Wayland** (X의 후속, Xorg 대체 진행 중) |
| 특징 | **네트워크 투명성**, 클라이언트-서버 구조, 플랫폼 독립 |

### X의 클라이언트-서버 구조 (헷갈림 주의 ★)
> **X 서버 = 디스플레이(모니터·키보드·마우스)가 있는 쪽**
> **X 클라이언트 = 응용 프로그램(GUI 앱)**

즉 **내 앞의 모니터가 X 서버**이고, 원격 서버에서 돌아가는 프로그램이 X 클라이언트입니다. 일반적인 서버/클라이언트 개념과 반대라서 시험에 자주 나옵니다.

### 통신 프로토콜
**X 프로토콜(XDMCP 포함)** — TCP **6000번 포트**부터 사용 (`DISPLAY :0` → 6000, `:1` → 6001)

### DISPLAY 환경변수
```
DISPLAY=호스트명:디스플레이번호.스크린번호
예: DISPLAY=:0.0          (로컬 첫 번째 디스플레이)
    DISPLAY=192.168.1.10:0.0
```
```bash
echo $DISPLAY
export DISPLAY=192.168.1.10:0.0     # 원격 디스플레이로 출력 지정
```

### 접근 제어
```bash
xhost +                        # 모든 호스트 허용 (보안상 위험)
xhost -                        # 모든 호스트 차단
xhost +192.168.1.10            # 특정 호스트 허용 ★
xhost -192.168.1.10            # 특정 호스트 차단
xauth list                     # 인증 쿠키(MIT-MAGIC-COOKIE) 목록
```

### 원격 X 사용
```bash
ssh -X user@host               # SSH X11 포워딩 ★ (안전한 방법)
ssh -Y user@host               # 신뢰된 포워딩
```

## 2. 윈도 매니저와 데스크톱 환경

### 윈도 매니저(Window Manager)
창의 테두리·이동·크기 조절 등 **창 관리만** 담당
예: **twm, mwm, fvwm, Enlightenment, Metacity, Mutter, Kwin, Compiz, i3, openbox**

### 데스크톱 환경(Desktop Environment)
윈도 매니저 + 파일 관리자 + 패널 + 응용 프로그램 **통합 환경**

| 환경 | 기반 툴킷 | 특징 |
|---|---|---|
| **GNOME** | **GTK+** | 심플·직관적, RHEL/Ubuntu 기본 |
| **KDE (Plasma)** | **Qt** | 화려하고 설정 옵션 많음 |
| **XFCE** | GTK+ | 경량, 저사양 PC |
| **LXDE / LXQt** | GTK+ / Qt | 초경량 |
| **Unity** | GTK+ | 과거 Ubuntu 기본 |
| **MATE** | GTK+ | GNOME 2 포크 |
| **Cinnamon** | GTK+ | Linux Mint 기본 |

### 출제 포인트
- **GNOME = GTK+**, **KDE = Qt** (툴킷 매칭 단골)
- 윈도 매니저 ≠ 데스크톱 환경

## 3. 디스플레이 매니저와 X 실행

### 디스플레이 매니저 (그래픽 로그인 화면)
| 매니저 | 관련 환경 |
|---|---|
| **XDM** | X 기본 |
| **GDM** | GNOME |
| **KDM / SDDM** | KDE |
| **LightDM** | 경량, Ubuntu |

### X 실행·설정 명령
```bash
startx                      # X 윈도 수동 시작
xinit                       # 저수준 X 시작
Xorg -configure              # xorg.conf 생성
X -configure
xrandr                      # 해상도·모니터 설정 확인/변경
xrandr -s 1920x1080
xdpyinfo                    # X 서버 정보
xwininfo                    # 창 정보
xkill                       # 클릭으로 창 강제 종료
xlsfonts                    # 폰트 목록
xset q                      # X 설정 조회
```

### 설정 파일
| 파일 | 역할 |
|---|---|
| `/etc/X11/xorg.conf` | X 서버 설정 (최신 배포판은 자동 감지로 없는 경우가 많음) |
| `/etc/X11/xorg.conf.d/` | 분할 설정 |
| `~/.xinitrc` | 사용자별 X 시작 스크립트 |
| `~/.Xresources` | X 애플리케이션 리소스 |
| `~/.xsession` | 세션 시작 스크립트 |

### xorg.conf 주요 섹션
`ServerLayout`, `Files`, `Module`, `InputDevice`, `Monitor`, `Device`(그래픽카드), `Screen`

### X 관련 종료·전환
| 키 | 기능 |
|---|---|
| `Ctrl + Alt + Backspace` | X 서버 강제 종료(설정에 따라 비활성) |
| `Ctrl + Alt + F1~F6` | 텍스트 가상 콘솔로 전환 |
| `Ctrl + Alt + F7` (또는 F2) | X 윈도로 복귀 |

### GUI ↔ CLI 전환 (systemd)
```bash
systemctl isolate multi-user.target      # CLI로 전환
systemctl isolate graphical.target       # GUI로 전환
systemctl set-default multi-user.target  # 부팅 기본값을 CLI로
```

## 4. 사용자 계정 관리

### 관련 파일 (필드 구조 암기 ★★★)

#### `/etc/passwd` — 7개 필드
```
root:x:0:0:root:/root:/bin/bash
 (1) (2)(3)(4) (5)  (6)    (7)
```
| 필드 | 내용 |
|---|---|
| 1 | 사용자명(로그인 ID) |
| 2 | 패스워드 → **`x`는 shadow 파일 사용 의미** |
| 3 | **UID** |
| 4 | **GID** |
| 5 | 설명(comment, 실명) |
| 6 | **홈 디렉터리** |
| 7 | **로그인 쉘** |

#### `/etc/shadow` — 9개 필드 (암호화된 비밀번호)
```
root:$6$xyz...:19000:0:99999:7:::
 (1)   (2)     (3) (4) (5) (6)(7)(8)(9)
```
| 필드 | 내용 |
|---|---|
| 1 | 사용자명 |
| 2 | **암호화된 패스워드** (`!`/`*`= 잠김, 빈칸 = 패스워드 없음) |
| 3 | 마지막 변경일 (1970-01-01부터 일수) |
| 4 | **최소 사용일수** (변경 후 이 기간 내 재변경 불가) |
| 5 | **최대 사용일수** (만료일) |
| 6 | 경고 일수 (만료 전 경고) |
| 7 | 유예(비활성) 기간 |
| 8 | 계정 만료일 |
| 9 | 예약 필드 |

#### `/etc/group` — 4개 필드
```
wheel:x:10:user1,user2
 (1) (2)(3)   (4)
```
| 필드 | 내용 |
|---|---|
| 1 | 그룹명 |
| 2 | 그룹 패스워드(`x` = gshadow 사용) |
| 3 | **GID** |
| 4 | **그룹 멤버 목록**(2차 그룹) |

#### 기타
- `/etc/gshadow` — 그룹 패스워드
- `/etc/login.defs` — 계정 생성 기본 정책(UID 범위, 패스워드 만료 등)
- `/etc/default/useradd` — useradd 기본값
- **`/etc/skel/`** — **새 계정 홈 디렉터리에 복사되는 기본 파일 템플릿** ★

### UID 관례 (출제 포인트)
| UID | 용도 |
|---|---|
| **0** | **root (슈퍼유저)** |
| 1 ~ 199 (또는 1~499) | 시스템 계정 |
| 200 ~ 999 | 시스템 데몬 계정 |
| **1000 이상** | **일반 사용자** (최신 배포판) |

> UID를 0으로 만들면 root와 동일한 권한을 가집니다 (보안 점검 항목).

### 계정 관리 명령
```bash
useradd user1                       # 계정 생성
useradd -u 1500 user1               # UID 지정
useradd -g users user1              # 기본 그룹 지정
useradd -G wheel,dev user1          # 2차 그룹 지정
useradd -d /data/user1 user1        # 홈 디렉터리 지정
useradd -s /bin/bash user1          # 쉘 지정
useradd -s /sbin/nologin user1      # 로그인 불가 계정 ★
useradd -m user1                    # 홈 디렉터리 생성
useradd -M user1                    # 홈 디렉터리 생성 안 함
useradd -e 2026-12-31 user1         # 계정 만료일
useradd -c "Hong Gildong" user1     # 설명

passwd user1                        # 패스워드 설정
passwd -l user1                     # 계정 잠금(lock) ★
passwd -u user1                     # 잠금 해제(unlock)
passwd -d user1                     # 패스워드 삭제
passwd -S user1                     # 패스워드 상태 확인
passwd -e user1                     # 다음 로그인 시 강제 변경
passwd -n 7 -x 90 -w 7 user1        # 최소/최대/경고 일수

usermod -l newname oldname          # 이름 변경
usermod -u 2000 user1               # UID 변경
usermod -g users user1              # 기본 그룹 변경
usermod -aG wheel user1             # ★ 2차 그룹 추가 (-a 없으면 기존 그룹 제거!)
usermod -L user1                    # 계정 잠금
usermod -U user1                    # 잠금 해제
usermod -s /bin/csh user1           # 쉘 변경
usermod -d /new/home -m user1       # 홈 디렉터리 변경 + 이동
usermod -e 2026-12-31 user1         # 만료일

userdel user1                       # 계정 삭제 (홈 디렉터리 유지)
userdel -r user1                    # ★ 홈 디렉터리·메일까지 삭제

groupadd dev                        # 그룹 생성
groupadd -g 2000 dev                # GID 지정
groupmod -n newdev dev              # 그룹명 변경
groupmod -g 3000 dev                # GID 변경
groupdel dev                        # 그룹 삭제
gpasswd -a user1 dev                # 그룹에 사용자 추가
gpasswd -d user1 dev                # 그룹에서 사용자 제거
gpasswd -A user1 dev                # 그룹 관리자 지정

chage -l user1                      # 패스워드 만료 정보 조회 ★
chage -M 90 user1                   # 최대 사용일수 90일
chage -m 7 user1                    # 최소 사용일수
chage -W 7 user1                    # 경고 일수
chage -E 2026-12-31 user1           # 계정 만료일
chage -d 0 user1                    # 다음 로그인 시 패스워드 변경 강제

id user1                            # UID/GID/그룹 확인
groups user1                        # 소속 그룹
su - user1                          # 사용자 전환 (- 는 환경까지 전환) ★
su -c "command" user1               # 명령만 실행
sudo command                        # 관리자 권한으로 실행
visudo                              # /etc/sudoers 안전하게 편집
newgrp dev                          # 기본 그룹 임시 변경
pwck / grpck                        # passwd/group 파일 무결성 검사
pwconv / pwunconv                   # shadow 사용/해제
```

### 출제 포인트
- `usermod -G`만 쓰면 **기존 2차 그룹이 모두 사라집니다.** 추가할 때는 반드시 **`-aG`**
- `userdel -r` = 홈 디렉터리까지 삭제
- `su` vs `su -`: 하이픈을 붙이면 **대상 사용자의 환경변수까지 완전히 전환**
- 로그인 차단 쉘: `/sbin/nologin`, `/bin/false`

## 5. 로그 관리

### 주요 로그 파일 (`/var/log/`) — 암기 ★
| 파일 | 내용 |
|---|---|
| **`/var/log/messages`** | **시스템 전반의 일반 로그** (RHEL 계열) |
| `/var/log/syslog` | 시스템 일반 로그 (Debian 계열) |
| **`/var/log/secure`** | **인증·보안 관련** (로그인 성공/실패, su, sudo) — RHEL |
| `/var/log/auth.log` | 인증 로그 (Debian) |
| `/var/log/boot.log` | 부팅 메시지 |
| `/var/log/dmesg` | 커널 링 버퍼 메시지 (`dmesg` 명령) |
| `/var/log/cron` | cron 실행 로그 |
| `/var/log/maillog` | 메일 로그 |
| **`/var/log/wtmp`** | **로그인/로그아웃 기록** (바이너리) → `last` 명령 |
| **`/var/log/btmp`** | **로그인 실패 기록** (바이너리) → `lastb` 명령 |
| **`/var/log/lastlog`** | **사용자별 최근 로그인** → `lastlog` 명령 |
| `/var/run/utmp` | **현재 로그인 중인 사용자** → `who`, `w` |
| `/var/log/xferlog` | FTP 전송 로그 |
| `/var/log/httpd/` | 아파치 access_log, error_log |

### 바이너리 로그는 cat으로 볼 수 없습니다 (출제 포인트)
| 로그 파일 | 확인 명령 |
|---|---|
| `wtmp` | `last` |
| `btmp` | `lastb` |
| `lastlog` | `lastlog` |
| `utmp` | `who`, `w`, `users` |

### 로그 데몬
| 데몬 | 설정 파일 |
|---|---|
| `syslogd` (구) | `/etc/syslog.conf` |
| **`rsyslogd`** (현재) | **`/etc/rsyslog.conf`** |
| `journald` (systemd) | `/etc/systemd/journald.conf`, 조회는 `journalctl` |

### rsyslog 설정 형식
```
facility.priority        action
*.info;mail.none         /var/log/messages
authpriv.*               /var/log/secure
mail.*                   -/var/log/maillog
cron.*                   /var/log/cron
*.emerg                  :omusrmsg:*
kern.*                   @192.168.1.10      # 원격 전송
```

#### Facility (로그 발생 장소)
`kern`, `user`, `mail`, `daemon`, `auth`, `authpriv`, `syslog`, `lpr`, `news`, `uucp`, `cron`, `local0~7`

#### Priority (심각도 — 낮은 순서부터 암기 ★)
| 순위 | 레벨 | 의미 |
|---|---|---|
| 0 | **emerg** (panic) | 시스템 사용 불가 — 가장 심각 |
| 1 | **alert** | 즉시 조치 필요 |
| 2 | **crit** | 치명적 |
| 3 | **err** (error) | 오류 |
| 4 | **warning** (warn) | 경고 |
| 5 | **notice** | 정상이지만 주의 |
| 6 | **info** | 정보 |
| 7 | **debug** | 디버깅 — 가장 상세 |

> 암기: **emerg - alert - crit - err - warning - notice - info - debug** (심각 → 가벼움)
> `*.info`로 지정하면 **info 이상(더 심각한) 모든 레벨**이 기록됩니다.
> `.none`은 해당 facility 제외, `=`는 해당 레벨만, `!`는 제외.

### 로그 순환 — logrotate
설정: `/etc/logrotate.conf`, `/etc/logrotate.d/`
```
/var/log/httpd/*log {
    daily              # 주기 (daily/weekly/monthly)
    rotate 4           # 4개 보관
    compress           # 압축
    missingok          # 없어도 에러 없음
    notifempty         # 비어있으면 순환 안 함
    create 0644 root root
}
```

### journalctl (systemd)
```bash
journalctl                    # 전체 로그
journalctl -f                 # 실시간
journalctl -u sshd            # 특정 유닛
journalctl -b                 # 현재 부팅 이후
journalctl -p err             # err 이상만
journalctl --since "1 hour ago"
journalctl --since today
journalctl -n 50              # 최근 50줄
journalctl --disk-usage       # 로그 용량
```

## 6. 백업

### 백업 도구
| 명령 | 특징 |
|---|---|
| **`tar`** | 가장 일반적. 아카이브 + 압축 |
| **`dd`** | **블록 단위 복제** — 디스크/파티션 전체 이미지 |
| **`dump` / `restore`** | ext 파일시스템 전용, **증분 백업 레벨(0~9)** 지원 |
| **`rsync`** | **증분·차등 동기화**, 네트워크 전송 |
| `cpio` | 아카이브 (find와 조합) |
| `mt` | 테이프 장치 제어 |
| `amanda`, `bacula` | 네트워크 통합 백업 솔루션 |

```bash
# tar 백업/복원
tar zcvf /backup/home_$(date +%F).tar.gz /home
tar zxvf /backup/home.tar.gz -C /

# dd — 디스크 이미지
dd if=/dev/sda of=/backup/sda.img bs=1M        # 백업
dd if=/backup/sda.img of=/dev/sda bs=1M        # 복원
dd if=/dev/zero of=/swapfile bs=1M count=1024  # 파일 생성
# if=input file, of=output file, bs=block size, count=블록 수

# dump / restore
dump -0uf /backup/full.dump /home     # 레벨 0 = 전체 백업
dump -1uf /backup/inc1.dump /home     # 레벨 1 = 증분
restore -rf /backup/full.dump

# rsync
rsync -av /home/ /backup/home/               # 로컬 동기화
rsync -avz -e ssh /home/ user@host:/backup/  # 원격(압축·SSH)
rsync -av --delete /home/ /backup/home/      # 원본에 없는 파일 삭제
```

| rsync 옵션 | 의미 |
|---|---|
| `-a` | 아카이브 (권한·시간·링크 보존) |
| `-v` | 상세 출력 |
| `-z` | 전송 시 압축 |
| `-e ssh` | SSH를 통해 전송 |
| `--delete` | 원본에 없는 대상 파일 삭제 |
| `-n` / `--dry-run` | 실제 수행 없이 테스트 |

### 백업 종류
| 종류 | 설명 |
|---|---|
| **전체(Full)** | 모든 데이터 백업. 복구 간단, 용량·시간 많음 |
| **증분(Incremental)** | **직전 백업 이후** 변경분만. 백업 빠름, **복구 복잡** |
| **차등(Differential)** | **최초 전체 백업 이후** 변경분 전체. 증분보다 용량 큼, 복구 단순 |

## 7. RAID (네트워크관리사에서도 출제)

| 레벨 | 방식 | 최소 디스크 | 특징 |
|---|---|---|---|
| **RAID 0** | 스트라이핑(Striping) | 2개 | **성능↑, 내결함성 없음** |
| **RAID 1** | 미러링(Mirroring) | 2개 | **안정성↑, 가용 용량 50%** |
| RAID 2 | 해밍 코드 ECC | 3개 | 실사용 안 함 |
| RAID 3 | 바이트 단위 + 전용 패리티 | 3개 | |
| RAID 4 | 블록 단위 + 전용 패리티 | 3개 | 패리티 디스크 병목 |
| **RAID 5** | 블록 스트라이핑 + **분산 패리티** | **3개** | 성능·안정성 균형. **디스크 1개 장애 허용** |
| **RAID 6** | 이중 분산 패리티 | **4개** | **디스크 2개 장애 허용** |
| **RAID 0+1 / 1+0(10)** | 스트라이핑 + 미러링 | 4개 | 고성능 + 고안정성 |

리눅스 소프트웨어 RAID 명령: `mdadm`
```bash
mdadm --create /dev/md0 --level=5 --raid-devices=3 /dev/sdb1 /dev/sdc1 /dev/sdd1
mdadm --detail /dev/md0
cat /proc/mdstat
```

## 8. 프린터·주변장치 관리

### 인쇄 시스템
| 시스템 | 특징 |
|---|---|
| **LPD / LPRng** | 구형 BSD 계열 |
| **CUPS** (Common UNIX Printing System) | **현재 표준**. IPP 프로토콜, **631번 포트**, 웹 관리(`http://localhost:631`) |

### 인쇄 명령 (System V / BSD 계열 구분 ★)
| 기능 | BSD 계열 | System V 계열 |
|---|---|---|
| 인쇄 요청 | `lpr file` | `lp file` |
| 대기열 확인 | `lpq` | `lpstat` |
| 작업 취소 | `lprm` | `cancel` |
| 프린터 제어 | `lpc` | - |

```bash
lpr -P printer1 file.txt       # 특정 프린터로 인쇄
lpr -#3 file.txt               # 3부 인쇄
lpq -P printer1                # 대기열
lprm 12                        # 12번 작업 삭제
lpstat -a                      # 프린터 상태
lpadmin                        # 프린터 추가·설정
```
설정 파일: `/etc/cups/cupsd.conf`, `/etc/cups/printers.conf`, 구 시스템은 `/etc/printcap`

### 사운드
| 시스템 | 설명 |
|---|---|
| **OSS** (Open Sound System) | 구형 |
| **ALSA** (Advanced Linux Sound Architecture) | **현재 표준 커널 사운드** |
| **PulseAudio** | 사운드 서버(믹싱) |
| **SANE** | **스캐너** 표준 (`scanimage`, `xsane`) |

### 장치 정보 확인 명령
```bash
lspci                # PCI 장치 목록 (그래픽·NIC) ★
lsusb                # USB 장치 목록
lscpu                # CPU 정보
lsblk                # 블록 장치
lsmod                # 로드된 커널 모듈 목록 ★
modprobe module      # 모듈 로드(의존성 자동)
modprobe -r module   # 모듈 제거
insmod module.ko     # 모듈 삽입(의존성 미해결)
rmmod module         # 모듈 제거
modinfo module       # 모듈 정보
dmesg                # 커널 메시지 (장치 인식 확인)
dmesg | tail
hdparm /dev/sda      # 하드디스크 파라미터
smartctl -a /dev/sda # 디스크 건강 상태
```

## 9. 마무리 체크 문제

1. X 윈도에서 모니터가 있는 쪽은 서버인가 클라이언트인가? → **서버**
2. X 윈도의 기본 포트 번호? → **6000**
3. GNOME과 KDE의 기반 툴킷? → **GTK+ / Qt**
4. `DISPLAY=:0.0`의 의미? → 로컬 호스트의 0번 디스플레이, 0번 스크린
5. 특정 호스트에 X 접근을 허용하는 명령? → `xhost +192.168.1.10`
6. `/etc/passwd`의 필드 개수와 7번째 필드? → **7개, 로그인 쉘**
7. `/etc/shadow`의 2번째 필드? → **암호화된 패스워드**
8. 새 계정 홈에 복사되는 템플릿 디렉터리? → **`/etc/skel/`**
9. root의 UID? → **0**
10. 기존 2차 그룹을 유지하며 그룹을 추가하는 옵션? → **`usermod -aG`**
11. 홈 디렉터리까지 삭제하며 계정 삭제? → `userdel -r`
12. 패스워드 만료 정보를 확인하는 명령? → `chage -l`
13. 로그인 실패 기록 파일과 확인 명령? → **`/var/log/btmp`, `lastb`**
14. 인증 관련 로그 파일(RHEL)? → **`/var/log/secure`**
15. syslog 심각도 중 가장 심각한 것과 가장 낮은 것? → **emerg / debug**
16. 로그 순환을 담당하는 도구? → **logrotate**
17. 디스크 전체를 블록 단위로 복제하는 명령? → **`dd`**
18. 최소 3개 디스크로 분산 패리티를 쓰는 RAID? → **RAID 5**
19. 현재 표준 인쇄 시스템과 포트? → **CUPS, 631**
20. 로드된 커널 모듈 목록을 보는 명령? → `lsmod`
