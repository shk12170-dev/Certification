## A. 헷갈리기 쉬운 옵션 — 최우선 암기 ★★★

| 명령 | 옵션 | 의미 | 함정 |
|---|---|---|---|
| `tar` | `z` / `j` / `J` | gzip / bzip2 / xz | 소문자 j = bzip2, **대문자 J = xz** |
| `tar` | `c` / `x` / `t` / `r` / `u` | 생성 / 풀기 / **목록** / 추가 / 갱신 | `t` = list |
| `ps` | `-ef` / `aux` | System V / **BSD** 스타일 | `aux`는 하이픈 없음 |
| `grep` | `-v` | **일치하지 않는** 행 | `-i`는 대소문자 무시 |
| `grep` | `-c` / `-l` | 개수 / 파일명만 | |
| `find` | `-atime`/`-mtime`/`-ctime` | 접근 / 내용수정 / 속성변경 | |
| `find` | `-perm -4000` | SetUID 검색 | |
| `kill` | 기본값 | **15 (SIGTERM)** | -9 아님 |
| `cp` | `-r` / `-p` / `-a` | 재귀 / 속성보존 / 아카이브 | 디렉터리는 `-r` 필수 |
| `rm` | `-r` / `-f` / `-i` | 재귀 / 강제 / 확인 | |
| `wc` | `-l` / `-w` / `-c` | 행 / 단어 / 바이트 | `-l`=line |
| `df` / `du` | - | **파일시스템** 여유 / **디렉터리** 사용량 | 혼동 최다 |
| `usermod` | `-aG` vs `-G` | 추가 vs **덮어쓰기** | `-a` 없으면 기존 그룹 소실 |
| `userdel` | `-r` | 홈 디렉터리까지 삭제 | |
| `rpm` | `-qf` / `-ql` | 파일 → 패키지 / 패키지 → 파일 | |
| `rpm` | `-i`/`-U`/`-F`/`-e` | 설치/업그레이드/갱신만/삭제 | |
| `apt` | `update` vs `upgrade` | 목록 갱신 vs 업그레이드 | yum과 반대 |
| `head`/`tail` | `-n` / `-f` | 줄 수 / **실시간 추적** | `tail -f` 단골 |
| `ln` | `-s` | 심볼릭 링크 | 없으면 하드 링크 |
| `sort` | `-n` / `-r` / `-u` / `-k` | 숫자 / 역순 / 중복제거 / 필드 | |
| `chmod` | `4/2/1` | SetUID / SetGID / Sticky | |
| `nice` | `-20 ~ 19` | **작을수록 우선순위 높음** | 음수는 root만 |


### 8진수 ↔ 기호 즉답표
```
7 = rwx    6 = rw-    5 = r-x    4 = r--
3 = -wx    2 = -w-    1 = --x    0 = ---
```
### umask 계산
```
파일     = 666 - umask
디렉터리 = 777 - umask
022 → 644 / 755      027 → 640 / 750      077 → 600 / 700
```
