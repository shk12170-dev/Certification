## 3. 최다 함정 10선

### ① `df` vs `du`
- **`df`** = 파일시스템(파티션) 단위 **여유 공간**
- **`du`** = 디렉터리/파일 단위 **사용량**

### ② `apt update` vs `yum update`
- `apt update` = **패키지 목록만 갱신** (업그레이드는 `apt upgrade`)
- `yum update` = **실제 업그레이드**

### ③ `usermod -G` vs `-aG`
- `-G`만 쓰면 **기존 2차 그룹이 전부 사라짐**
- 추가할 때는 반드시 **`-aG`**

### ④ X 윈도의 서버/클라이언트
- **X 서버 = 모니터·키보드가 있는 내 쪽**
- X 클라이언트 = 응용 프로그램
- 일반 상식과 **반대**

### ⑤ `tar` 압축 문자
- `z` = gzip, `j` = bzip2, **`J`(대문자)** = xz
- `t` = **목록 보기** (테스트가 아님)

### ⑥ ext2 vs ext3
- 차이는 **저널링(Journaling) 유무**. ext2에는 없음.

### ⑦ 하드 링크의 제약
- **디렉터리에 만들 수 없고, 다른 파일시스템에도 만들 수 없음**
- 원본 삭제해도 데이터 유지 (심볼릭 링크는 깨짐)

### ⑧ 대문자 `S` / `T`
- `rwS` = SetUID는 있으나 **실행 권한(x) 없음** → 작동 안 함
- 소문자 `s`/`t`가 정상

### ⑨ `rpm` 삭제 시 인자
- 설치는 **파일명**(`httpd-2.4.rpm`), 삭제는 **패키지명**(`httpd`)

### ⑩ 사설 IP 172 대역
- **172.16 ~ 172.31**까지만. `172.32.x.x`는 공인 IP

## 5. 시그널 · 런레벨 · 로그 레벨

### 시그널
```
1  HUP   설정 재읽기 / 터미널 종료
2  INT   Ctrl+C
3  QUIT  Ctrl+\ (코어 덤프)
9  KILL  강제 종료 (무시 불가)
15 TERM  정상 종료 (kill 기본값)
18 CONT  계속 실행
19 STOP  중지 (무시 불가)
20 TSTP  Ctrl+Z
```

### 런레벨 ↔ systemd 타깃
```
0 halt        → poweroff.target
1 single      → rescue.target
2 NFS없는 다중 → multi-user.target
3 CLI         → multi-user.target
4 미사용
5 GUI         → graphical.target
6 reboot      → reboot.target
```

### 로그 심각도 (심각 → 경미)
```
emerg → alert → crit → err → warning → notice → info → debug
```

## 7. crontab 즉답 훈련

| 표현 | 의미 |
|---|---|
| `0 0 * * *` | 매일 자정 |
| `0 3 * * *` | 매일 03:00 |
| `30 4 * * 0` | 매주 일요일 04:30 |
| `0 9 * * 1-5` | 평일 09:00 |
| `*/15 * * * *` | 15분마다 |
| `0 */6 * * *` | 6시간마다 |
| `15 14 1 * *` | 매월 1일 14:15 |
| `0 0 1 1 *` | 매년 1월 1일 자정 |
| `0 12 * * 6` | 매주 토요일 12:00 |

| 5분마다 | `*/5 * * * *` |

요일: **0 또는 7 = 일요일**, 1 = 월요일 … 6 = 토요일

## 8. 2차 시험 2과목(리눅스 활용) 과락 방지 핵심 20개

1. X 서버 = 모니터가 있는 쪽, 포트 6000, `DISPLAY=:0.0`
2. GNOME = GTK+, KDE = Qt
3. 디스플레이 매니저: XDM, GDM, KDM/SDDM, LightDM
4. `xhost +IP` = 특정 호스트 X 접근 허용
5. 윈도 매니저 ≠ 데스크톱 환경
6. `ONBOOT=yes`, `BOOTPROTO=static|dhcp`
7. `/etc/resolv.conf` = DNS 지정, `/etc/hosts`가 DNS보다 우선
8. `netstat -tulnp` / `ss -tulnp` = LISTEN 포트
9. `route -n` / `ip route` = 게이트웨이 확인
10. `ping -c 4`, `traceroute`, `dig`, `ethtool`
11. NFS = `/etc/exports` (Unix↔Unix), Samba = `smb.conf` (Linux↔Windows)
12. SSH 22, Telnet 23(평문), SFTP/SCP 22
13. DHCP = **DORA**, 실패 시 169.254.x.x
14. FTP: Active(서버→클라), Passive(클라→서버)
15. POP3(110) = 다운로드, IMAP(143) = 서버 보관
16. CSMA/CD = 유선, CSMA/CA = 무선
17. TCP Wrapper: `hosts.allow` → `hosts.deny` 순서
18. SELinux: enforcing / permissive / disabled
19. IaaS / PaaS / SaaS 구분
20. 컨테이너는 **호스트 커널 공유** → 가볍고 빠름

## 9. 시험장에서의 전략

1. **쉬운 명령어 문제부터 먼저 푸세요.** 80문항 100분 = 문항당 75초. 헤매면 안 됩니다.
2. **모르는 문제는 표시하고 넘어가세요.** 끝까지 한 바퀴 돌고 돌아옵니다.
3. **옵션 문자를 소리 내어 읽듯 확인하세요.** `-j`와 `-J`, `-e`와 `-E`를 눈으로만 보면 틀립니다.
4. **2과목(네트워크·활용)에서 최소 13문항 이상 맞히는 것**을 목표로 잡으세요. 과락선이 12.8점입니다.
5. 확실한 오답을 먼저 지우는 소거법이 잘 통하는 시험입니다.
